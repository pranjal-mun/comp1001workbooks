List basics

1. Values, indexes, and length

A list stores values in a specified order. Each value is an element. A list can contain different types of values. These examples use one type of value in each list.

letters is ["c", "a", "t"]. The list marks has four elements.

The first index is 0, as in a string. A negative index gives a position from the end.

len(marks) returns the number of elements. In this example, the length is 4. For a list with elements, the last index from the start is len(marks) - 1.

marks[4] causes an IndexError. An empty list has a length of 0. An empty list has no valid element index.

2. Mutable lists and immutable strings

A list is mutable. You can replace an element in the same list.

List changes

4. Adding elements

append adds one element at the end. insert adds one element before an index.

The indexes of later elements increase by one. The length increases by one.

extend adds each element from another sequence to the list.

a has four elements.

b has three elements. The last element is a list. a + [50, 60] makes a new list. a.extend([50, 60]) changes a.

7. Slices and separate lists

marks[start:stop] makes a new list. The slice includes start and excludes stop.

The slice marks[1:3] contains the elements at indexes 1 and 2.

For these lists of numbers, a slice makes a separate list. A change to the slice does not change the original list.

There are two lists. Each list starts at index 0.

Aliasing and copying

8. Two names for one list

A list variable stores a reference to a list. b = a copies that reference.

This relation is aliasing. A change through either name changes the same list.

backup refers to the same list as marks.

After statementList for both names
backup = marks[60, 70, 80]
backup.append(90)[60, 70, 80, 90]
marks[0] = 65[65, 70, 80, 90]
backup.pop(1)[65, 80, 90]

The name backup does not make a copy.

A string or number is immutable, like the string in Section 2. The assignment b = a causes no problem for these values because they cannot change in place.

9. Making a separate copy

a[:] makes a new list with the same elements. list(a) also makes a new list.

You can also use b = list(a) to make a separate copy. There are two separate lists. The assignment b = a.copy() also makes a separate copy.

List operations

CodeMeaning
a = [10, 20], a = []The list contains initial values or is empty.
len(a), a[i], a[-1]These give the length, element i, or the last element.
a[i] = valueThe assignment replaces element i.
a.append(x)The method adds one element at the end.
a.insert(i, x), a.extend(b)insert adds before i. extend adds the elements of b.
a.remove(x)The method removes the first match. No match causes a ValueError.
x = a.pop(i), del a[i]Both remove by index. pop also returns the element.
x in a, a.index(x), a.count(x)The results give presence, the first index, or the number of matches.

index needs a match. pop and del need a valid index.
