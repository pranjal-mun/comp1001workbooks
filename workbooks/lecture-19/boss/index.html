How bosses work

These problems use the argument styles and the program layout from Lecture 19:

  • default parameter values
  • keyword calls
  • helper functions called from main()
  • the standard guard at the end of the file

They use only what Lectures 4 to 19 covered:

  • input() with int()
  • arithmetic
  • comparisons combined with and and or
  • if statements, while and for loops
  • string indexing and random.randint
  • functions that return values

Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Check also calls your functions directly with more values and compares what they return. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Problems 1 and 4 read their values with a plain input() that shows no prompt, so the output is only what your program prints. Keep the input lines exactly as the starter shows them. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show. Problems 2 and 3 read no keyboard input.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Centered text

Write the function center_text(text, width=24). It returns the text with spaces added in front, so that the text sits in the center of a line of the given width.

  • The spare space is the width minus the length of the text. Put half of it before the text.
  • When the spare space is odd, put the smaller half before the text.
  • Add no spaces after the text.
  • If the text is as wide as the width or wider, return it unchanged.

In main, read the text and then the width on separate lines. The width is a nonnegative integer. Call center_text with width as a keyword argument. Print the result between two | characters, so the spaces are visible.

Example 1
Input:
Hi
9
Output:
|   Hi|
Explanation:
There are seven spare positions, so three spaces go before Hi.
Example 2
Input:
wide
0
Output:
|wide|
Explanation:
The width is zero, so the text is returned unchanged.
Example 3
Input:

4
Output:
|  |
Explanation:
The text is empty, so the returned string contains two spaces.
Constraints
  • The text contains 0 through 80 characters, each occupying one position.
  • The width is an integer from 0 through 80.
  • Use the default width 24, a keyword call in main, and the standard guard.
  • Also test the helper with its width argument omitted.
TypedOutput
Hi, 9|   Hi|
wide, 0|wide|
an empty line, 4|  |
abc, 3|abc|
ab, 5| ab|
ab, 6|  ab|

Rules the checker enforces
  • Define center_text(text, width=24) with two parameters and the default width 24.
  • center_text returns the centered text. Check also calls it with ('Hi'), which uses the default width, and with values such as ('abc', 4), ('long text', 4), ('', 0), and an 80-character text with width 80.
  • In main, call center_text with width as a keyword argument.
  • Define main with empty parentheses and end the file with the standard guard.

Keep the lines text = input() and width = int(input()) unchanged. The checker will type the other lines.

👾 Boss 2: Ordinal words

An ordinal word names a position in order: first, second, third, fourth, fifth, sixth, seventh, eighth, ninth, tenth, eleventh, twelfth.

Write the function ordinal_word(number). For a number from 1 through 12 it returns the ordinal word. For any other integer it returns the empty string.

In main, use a loop to print each number from 1 through 12 followed by its ordinal word. The program reads no input.

Example 1
Input:
Run main; no keyboard input.
Output:
1 first
2 second
3 third
4 fourth
5 fifth
6 sixth
7 seventh
8 eighth
9 ninth
10 tenth
11 eleventh
12 twelfth
Explanation:
The loop prints one integer and its word on each line.
Example 2
Input:
print('|' + ordinal_word(0) + '|')
Output:
||
Explanation:
Zero is outside 1 through 12, so the function returns an empty string.
Constraints
  • The helper accepts an integer from -100 through 100.
  • Only values 1 through 12 have nonempty results.
  • Use a loop in main and end the file with the standard guard.
  • Check both outside boundaries, 0 and 13.
Rules the checker enforces
  • Define ordinal_word(number) with one parameter.
  • ordinal_word returns the word, or the empty string. Check calls it with every integer from -100 through 100, including 0 and 13.
  • Use a loop in main to print the twelve lines of Example 1.
  • Define main with empty parentheses and end the file with the standard guard.

🐉 Boss 3: Random plate codes

Write a program that prints one random plate code. A plate code has one of two formats. Choose each format with probability one half.

  • two uppercase letters followed by four digits
  • three digits followed by three uppercase letters

Letters and digits may repeat. A group of digits may start with zero. Write these functions:

  1. random_letters(count=2) returns count random uppercase letters as a string.
  2. random_digits(count=4) returns count random digits as a string.
  3. make_plate() chooses the format and calls the two helpers. When it needs a count other than the default, it passes the count as a keyword argument.
  4. main() prints one code. It reads no input.
Example 1
Input:
No keyboard input.
Random choices: format 0, letter indexes 0 and 25,
then digits 0, 4, 0, 7.
Output:
AZ0407
Explanation:
Format 0 uses two letters followed by four digits.
Example 2
Input:
No keyboard input.
Random choices: format 1, digits 0, 0, 0,
then letter indexes 1, 1, 1.
Output:
000BBB
Explanation:
Format 1 uses three digits followed by three letters.
Leading zeros and repeated characters are allowed.
Constraints
  • Each generated plate has six characters and uses only A through Z and 0 through 9.
  • Helper counts are integers from 0 through 6. A count of zero returns the empty string.
  • Use random.randint(a, b), which can return either endpoint as well as any integer between them.
  • Use loops, string indexing, default parameter values, keyword calls, main, and the standard guard.
  • The random choices shown in the examples describe particular runs. Other valid runs can print different codes.

For the two examples, Check replaces random.randint while make_plate() runs. A call random.randint(a, b) then returns a plus the next choice listed in the example. The choices are used in the order the example lists them: first the format, then the characters from left to right.

Rules the checker enforces
  • Define random_letters(count=2) and random_digits(count=4) with one parameter each and these defaults, and make_plate and main with empty parentheses.
  • Use random.randint(a, b) for every random choice.
  • Use a loop in each helper. random_letters(count) returns count uppercase letters and random_digits(count) returns count digits, for every count from 0 through 6.
  • In make_plate, call the helpers with no arguments for format 0 and with keyword arguments such as count=3 for format 1.
  • With the choices of Example 1, make_plate() returns AZ0407. With those of Example 2, it returns 000BBB.
  • In 200 calls, make_plate() returns six-character codes in both formats.
  • main prints one code. End the file with the standard guard.

💀 Boss 4: Magic date search

A magic date is a date where the day times the month equals the last two digits of the year. In Python the test is day * month == year % 100. For example, 2 February 2004 is a magic date because 2 times 2 is 4.

Write a program that reads a start year and an end year on separate lines. It prints every valid magic date from the start year to the end year, including both years. Print each date as the year, the month and the day, separated by single spaces. Print the dates in order of year, then month, then day. If there are no magic dates, print nothing.

Use these calendar rules for this exercise:

  • April, June, September and November have 30 days.
  • February has 29 days in a leap year and 28 days otherwise.
  • The other months have 31 days.
  • A leap year is divisible by 400, or divisible by 4 but not by 100.

Write these functions:

  1. is_leap_year(year) returns True for a leap year.
  2. days_in_month(month, year) returns the number of days in the month. It uses is_leap_year for February.
  3. is_magic_date(day, month, year) returns True only for a valid date that is magic. It returns False for an invalid month or day, and it uses days_in_month to check the day.
  4. main() reads the two years and searches the dates with nested loops.

After writing the program, trace the function frames. Stop at the moment when is_leap_year runs during the call is_magic_date(2, 2, 2004), made by the search in main. List the frames from bottom to top, and state where each waiting function resumes.

Example 1
Input:
2004
2004
Output:
2004 1 4
2004 2 2
2004 4 1
Explanation:
The valid month-day products equal 4, the final two digits of 2004.
Example 2
Input:
2000
2000
Output:

Explanation:
A positive month and day cannot have a product of zero.
Constraints
  • The start and end years satisfy 2000 <= start <= end <= 2099.
  • Each helper receives integer arguments. is_magic_date must return False for an invalid month or day.
  • Call days_in_month only after checking that the month is from 1 through 12.
  • Test February in 2000 and 2001, an invalid day such as February 30, and an invalid month such as 13.
  • Use the required helper chain, nested loops in main, and the standard guard.

Rules the checker enforces
  • Define is_leap_year(year), days_in_month(month, year), is_magic_date(day, month, year), and main with empty parentheses.
  • days_in_month uses is_leap_year, and is_magic_date uses days_in_month.
  • Each helper returns the right value. Check calls is_leap_year with years such as 1900, 2000, 2001, and 2100. It calls days_in_month with every month of 2000, 2001, 2004, and 2100. It calls is_magic_date with dates such as (30, 2, 2004), (29, 2, 2001), and (1, 13, 2013).
  • is_magic_date calls days_in_month only for a month from 1 through 12.
  • Put the nested search loops in main and end the file with the standard guard.

Keep the lines start = int(input()) and end = int(input()) unchanged. The checker will type the other years.

The frame trace

Trace the function frames while is_leap_year runs inside is_magic_date(2, 2, 2004). Check does not grade this part.

Show the answer

During the requested call, the function frames from bottom to top are main, is_magic_date, days_in_month, and is_leap_year. The module frame is below them. days_in_month resumes at its leap-year condition and returns 29. is_magic_date resumes at its day check, then returns True because 2 * 2 == 2004 % 100. main resumes at its magic-date condition and prints 2004 2 2.
