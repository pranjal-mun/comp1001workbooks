How bosses work

These problems use the loop algorithms from Lecture 16: an accumulator with a count, a running best, a sentinel loop that ends at a blank line, the previous-item pattern, and seeded random numbers from the random module. They use only what Lectures 4 to 16 covered: input() with int() and float(), arithmetic, math.sqrt(), string concatenation, if, elif and else, while and for loops, and random.seed(), random.randint() and random.choice(). Test the smallest case, such as an empty list of grades or a single value, as well as a typical case. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Keep the input lines exactly as the starter shows them: Check runs your program several times, typing a different sequence of answers each time, and every run must print exactly what the examples show. The two random problems seed the generator with the typed seed, so the same seed always gives the same numbers. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Term Grade Average

Given zero or more valid letter grades, produce their grade point average. Read one grade per line. A blank line ends the input. Use this table:

Points4.04.03.73.33.02.72.32.01.71.31.00.0

Print the average to two decimal places as Grade point average: followed by the value. If no grades are entered, print No grades entered.

Example 1

(blank line)

Output:

Explanation:
The three grade points are 4.0, 2.3, and 3.0. Their average is 3.10.
Example 2
Input:
(blank line)

Output:
No grades entered.

Explanation:
The first line is blank, so there is no value to average.
Constraints
  • Each nonblank line is one of the grades in the table, using the shown capital letters.
  • The first blank line ends the input.
  • Use a sentinel loop, an accumulator, a counter, and a safe empty-input check.

The program reads one grade per line with no prompt. The starter reads the first grade before the loop; read each later grade at the end of the loop body.

👾 Boss 2: Route Perimeter

Given the coordinates of at least two points on a closed walking route, produce its perimeter. Read the first x and y. Then read each later x; a blank x ends the input. For every nonblank x, read its y. The distance between (x1, y1) and (x2, y2) is math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2). Include the final segment back to the first point. Print the perimeter to two decimal places as Route perimeter: followed by the value.

Explanation:
The three segment lengths are 3, 4, and 5.
Example 2

Explanation:
The route goes 3 units to the second point and 3 units back to the first.
Constraints
  • Every coordinate is a valid floating-point number.
  • At least two points are supplied.
  • Use variables for the first point and the previous point.

The program reads one coordinate per line with no prompt: the first x, the first y, then x and y for each later point, and finally a blank line in place of an x. Read each later x as text so the blank line can be tested before converting.

🐉 Boss 3: Running Record Board

Given a seed and a positive count n, generate n random integers from 1 through 100. Produce each number on its own line. Add new record after a number that is larger than every earlier number. The first number is the initial record and does not count as an update. After the numbers, print the maximum as Maximum: and the number of updates as Updates:, each followed by the value.

Example 1
Input:
5
6

Output:
80
33
95 new record
46

Maximum: 95
Updates: 1

Explanation:
Only 95 replaces the initial record of 80.
Example 2
Input:
2
1

Output:
8
Maximum: 8
Updates: 0

Explanation:
One generated value becomes the initial record, so no later update occurs.
Constraints
  • n >= 1.
  • Use random.randint(1, 100) and seed the generator with the input seed.
  • Initialize the running maximum from the first generated value.

The program reads the seed on the first line and n on the second, with no prompt. The starter seeds the generator; every later call to random.randint(1, 100) then follows the same sequence, so the sixth number equal to 95 in Example 1 is expected.

  • Initialize the running maximum from the first generated value, not from 0.

💀 Boss 4: Three-in-a-Row Trials

Given a seed and positive number of trials, simulate fair coin flips until three identical outcomes occur in a row in each trial. Produce the flips on one line, followed by a colon, a space, and the number of flips. After all trials, print the average number of flips to two decimal places as Average flips: followed by the value. Use random.choice('HT').

Example 1
Input:
4
2

Output:
HTHTTHHH: 8
HTTHHTTHHTHHTTHHTTT: 19
Average flips: 13.50

Explanation:
Each line stops as soon as HHH or TTT appears. The average is (8 + 19) / 2.
Example 2
Input:
1
1

Output:
HHTHTTT: 7
Average flips: 7.00

Explanation:
The only trial ends with three tails in a row.
Constraints
  • trials >= 1.
  • Seed the random generator with the input seed.
  • Use an outer loop for trials and an inner loop for flips.
  • Track the previous outcome, current run length, flip count, and total flips.

The program reads the seed on the first line and the number of trials on the second, with no prompt. Print each trial's line with print(outcomes + ':', flips) so the colon touches the last flip and one space separates it from the count.

  • Print the result with two decimal places using :.2f.

Keep the lines seed = int(input()), trials = int(input()) and random.seed(seed) unchanged. The checker will type the other pairs.
