4. A sentinel marks the end of input

A sentinel is a special input value that means there are no more data values. The sentinel controls the loop but is not part of the data.

The following program reads marks until the user enters -1.

Sample run:

The loop tests the sentinel before adding or counting. Therefore, -1 is not included in the total or count.

6. A priming read prepares the first test

The input statement before a sentinel loop is a priming read. It gives the loop condition its first value.

The two reads have different moments but the same job: obtain the value for the next test. A priming-read loop is correct and often easy to trace. Its drawback is duplicated code. If one prompt changes and the other does not, the program becomes inconsistent.

7. while True with break avoids the duplicate read

while True begins a loop whose header never becomes false. A break statement leaves the nearest loop immediately.

Sample run:

Mark (-1 to finish): 72
Mark (-1 to finish): 84
Mark (-1 to finish): -1
Values entered: 2

The input appears once. The test occurs after reading but before processing. Use break for one clear exit when the condition cannot naturally be tested at the top. Several hidden break statements make a loop hard to trace.

8. Compare the two sentinel structures

Both structures can solve the same problem.

Priming-read loopwhile True with break
first read occurs before the loopevery read occurs inside the loop
condition is visible in the headerexit test appears after the read
input line appears twiceinput line appears once
natural when the first value is already availablenatural for a read-test-process cycle

The important order is the same in both:

  1. read a value;
  2. test whether it is the sentinel;
  3. process it only if it is data.

9. Plan the user conversation with a storyboard

A storyboard is a written sample of the prompts, user responses, and final output. It describes the interaction before the code is written.

Mark (-1 to finish): 72
Mark (-1 to finish): 84
Mark (-1 to finish): -1
Average of 2 marks: 78.00

This small plan answers useful questions:

  • Does the prompt clearly state the sentinel?
  • Is the sentinel ever printed as data?
  • What appears after the final input?
  • What should happen if the sentinel is entered immediately?

A storyboard is especially valuable for loops because the same prompt may appear many times during a real run.

10. Guard an average against empty input

An average needs both a total and a count. A sentinel loop may receive no data: the user can enter the sentinel immediately. Dividing by a count of 0 raises a ZeroDivisionError.

Sample run with data:

Mark (-1 to finish): 72
Mark (-1 to finish): 84
Mark (-1 to finish): -1
Average of 2 marks: 78.00

Sample run without data:

Mark (-1 to finish): -1
No marks were entered.

The guard tests count > 0 before division. Both possible paths produce a clear result.
