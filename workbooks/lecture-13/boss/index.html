How bosses work

These problems combine tracing and sentinel-controlled input with the while patterns from Lecture 12. They use only what Lectures 4 to 13 covered: input() with int() and float(), arithmetic including % and //, f-strings, if and else, and while loops with a sentinel or a counter. Test the sentinel-first or smallest useful case as well as a typical case. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with input(). Keep the input line exactly as the starter shows it: Check runs your program several times, typing a different sequence of answers at the prompts each time, and every run must print exactly what the sample runs show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Oliver's Treat Average

Oliver's daily treat count is always a nonnegative integer, so -1 can mark the end of the data. Read daily counts until the user enters -1. Do not include the sentinel in the total or count. If at least one day was entered, print the average with two digits after the decimal point. Otherwise, print No days were entered.

Sample run 1:

Treats (-1 to finish): 2
Treats (-1 to finish): 4
Treats (-1 to finish): 6
Treats (-1 to finish): -1
Average treats: 4.00

Sample run 2:

Treats (-1 to finish): -1
No days were entered.
TypedOutput
2, 4, 6, -1Average treats: 4.00
-1No days were entered.
5, -1Average treats: 5.00
0, 0, 3, -1Average treats: 1.00
1, 2, -1Average treats: 1.50
Rules the checker enforces
  • Keep the while True loop and leave it with exactly one break.
  • Test the sentinel and break before total and count are updated.
  • Test count > 0 before dividing by it.
  • Print the average with :.2f.
  • No import.

Keep the line treats = int(input('Treats (-1 to finish): ')) unchanged. The checker will type the other sequences.

👾 Boss 2: Campus Shop Cash Total

Read item prices for a Memorial University campus shop purchase. A blank line ends the input because it cannot be an item price. First print the card total to the nearest cent. Then print the cash total rounded to the nearest five cents. Work in cents for the final rounding: a remainder of 0, 1, or 2 cents rounds down, while a remainder of 3 or 4 cents rounds up. If the user enters a blank line immediately, both totals are $0.00.

Sample run 1:

Price, or blank to finish: $1.02
Price, or blank to finish: $2.01
Price, or blank to finish: $
Card total: $3.03
Cash total: $3.05

Sample run 2:

Price, or blank to finish: $
Card total: $0.00
Cash total: $0.00
TypedOutput

blankCard total: $0.00 then Cash total: $0.00
0.99, blankCard total: $0.99 then Cash total: $1.00
1.01, blankCard total: $1.01 then Cash total: $1.00

2.50, 2.50, blankCard total: $5.00 then Cash total: $5.00

Rules the checker enforces
  • Keep the while True loop and leave it with exactly one break.
  • Test text for the blank line before calling float() on it.
  • Convert the total to whole cents with round(), and use the remainder cents % 5 for the cash total.
  • Exactly two print() calls: the card total, then the cash total.
  • No import.

Keep the line text = input('Price, or blank to finish: $') unchanged. The checker will type the other sequences.

🐉 Boss 3: Square Root Check

Read a positive number and estimate its square root. Start with half of the number as the first guess. While the difference between guess * guess and the number is greater than 0.000001, replace the guess with the average of guess and number / guess. Count the updates. Print the final guess with six digits after the decimal point, followed by the update count.

Sample run 1:

Number: 4
Square root: 2.000000
Updates: 0

Sample run 2:

Number: 25
Square root: 5.000000
Updates: 5

The difference can be negative when the guess is too small, so measure it with abs(). Trace the run for 4 by hand: the first guess is already exact, so the loop body never runs.

TypedOutput
4Square root: 2.000000 then Updates: 0
25Square root: 5.000000 then Updates: 5
2Square root: 1.414214 then Updates: 4
100Square root: 10.000000 then Updates: 6
0.25Square root: 0.500000 then Updates: 5
1Square root: 1.000000 then Updates: 4
Rules the checker enforces
  • A while loop whose header tests the error with abs(guess * guess - number) against 0.000001. No break.
  • Estimate the root with the averaging step, not with ** 0.5 or a square-root function.
  • No import.

Keep the line number = float(input('Number: ')) and the two print lines unchanged. The checker will type the other numbers.

💀 Boss 4: Factor Trail

Read an integer that is at least 2. Print its prime factors in order, one per line. Begin with 2 as the possible factor. When the factor divides the remaining value exactly, print it and divide the remaining value by it. Otherwise, increase the possible factor by 1. Do not increase the factor after a successful division, because the same factor may occur again.

Sample run 1:

Number: 84
Prime factors:
2
2
3
7

Sample run 2:

Number: 13
Prime factors:
13

Trace 84 before you code: 84 becomes 42, then 21 (two 2s), 3 does not divide 21 until the factor reaches 3, which leaves 7, and 7 is printed when the factor catches up with it. The loop ends once the factor is larger than what remains.

TypedOutput
84Prime factors: then 2, 2, 3, 7
13Prime factors: then 13
2Prime factors: then 2
360Prime factors: then 2, 2, 2, 3, 3, 5
97Prime factors: then 97
1000Prime factors: then 2, 2, 2, 5, 5, 5
Rules the checker enforces
  • Exactly one while loop, ended by its own condition. No break.
  • Test whether the factor divides remaining exactly with %, and reduce remaining with //.
  • Each prime factor on its own line.
  • No import.

Keep the line number = int(input('Number: ')) unchanged. The checker will type the other numbers.
