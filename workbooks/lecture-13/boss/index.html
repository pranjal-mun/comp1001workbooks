How bosses work

These problems combine tracing and sentinel-controlled input with the while patterns from Lecture 12. They use only what Lectures 4 to 13 covered: input() with int() and float(), arithmetic including % and //, f-strings, if and else, and while loops with a sentinel or a counter. Test the sentinel-first or smallest useful case as well as a typical case. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with input(). Keep the input line exactly as the starter shows it: Check runs your program several times, typing a different sequence of answers at the prompts each time, and every run must print exactly what the sample runs show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Daily Treat Average

A pet gets a whole number of treats each day. You are given the daily counts one at a time, ended by -1. Print the average treats per day with two digits after the decimal point. If no day was entered before the -1, print No days were entered.

Read the counts with input() inside a while True loop, leave the loop with break when -1 arrives, and print once after the loop.

Example 1
Input: counts = 2, 4, 6, -1
Output: Average treats: 4.00
Explanation: (2 + 4 + 6) / 3 = 4. The -1 is not a day.
Example 2
Input: counts = -1
Output: No days were entered.
Example 3
Input: counts = 1, 2, -1
Output: Average treats: 1.50
Constraints
  • 0 <= treats <= 100 on each day
  • at most 50 days before the -1

The program reads each count after the prompt Treats (-1 to finish): .

Treats (-1 to finish): 2
Treats (-1 to finish): 4
Treats (-1 to finish): 6
Treats (-1 to finish): -1
Average treats: 4.00
TypedOutput
2, 4, 6, -1Average treats: 4.00
-1No days were entered.
5, -1Average treats: 5.00
0, 0, 3, -1Average treats: 1.00
1, 2, -1Average treats: 1.50
Rules the checker enforces
  • Keep the while True loop and leave it with exactly one break.
  • Test the sentinel and break before total and count are updated.
  • Test count > 0 before dividing by it.
  • Print the average with :.2f.
  • No import.

Keep the line treats = int(input('Treats (-1 to finish): ')) unchanged. The checker will type the other sequences.

👾 Boss 2: Shop Cash Total

At a shop, a card payment is charged to the cent and a cash payment is rounded to the nearest five cents. You are given item prices one at a time, ended by a blank line. Print the card total, then the cash total.

Round in whole cents: when the total divided by 5 leaves a remainder of 0, 1 or 2 cents, round down; when it leaves 3 or 4, round up.

Read each price with input() inside a while True loop, leave the loop with break on the blank line, and print twice after the loop.

Example 1
Input: prices = 1.02, 2.01, blank
Output:
Card total: $3.03
Cash total: $3.05
Explanation: 303 cents leaves a remainder of 3, so cash rounds up to 305.
Example 2
Input: prices = 1.01, blank
Output:
Card total: $1.01
Cash total: $1.00
Explanation: 101 cents leaves a remainder of 1, so cash rounds down to 100.
Example 3
Input: prices = blank
Output:
Card total: $0.00
Cash total: $0.00
Constraints
  • 0.01 <= price <= 999.99, with at most two digits after the decimal point
  • at most 50 prices before the blank line

The program reads each price after the prompt Price, or blank to finish: $.

🐉 Boss 3: Square Root Check

You are given a positive number, number. Estimate its square root. Start with number / 2 as the guess. While guess * guess is more than 0.000001 away from number, replace the guess with the average of guess and number / guess. Print the final guess with six digits after the decimal point, then the number of times the guess was replaced.

Read number with input(), improve the guess with a while loop whose header does the closeness test, and print twice after the loop.

Example 1
Input: number = 4
Output:
Square root: 2.000000
Updates: 0
Explanation: the first guess, 4 / 2 = 2, is already exact, so the loop body never runs.
Example 2
Input: number = 25
Output:
Square root: 5.000000
Updates: 5
Explanation: the guess goes 12.5, 7.25, 5.349138, 5.011394, 5.000013, 5.000000.
Example 3
Input: number = 0.25
Output:
Square root: 0.500000
Updates: 5
Explanation: the first guess, 0.125, is too small, so the guess grows before it settles.
Constraints
  • 0.01 <= number <= 1000000

The program reads the number after the prompt Number: .

Number: 25
Square root: 5.000000
Updates: 5
TypedOutput
4Square root: 2.000000 then Updates: 0
25Square root: 5.000000 then Updates: 5
2Square root: 1.414214 then Updates: 4
100Square root: 10.000000 then Updates: 6
0.25Square root: 0.500000 then Updates: 5
1Square root: 1.000000 then Updates: 4
Rules the checker enforces
  • A while loop whose header tests the error with abs(guess * guess - number) against 0.000001. No break.
  • Estimate the root with the averaging step, not with ** 0.5 or a square-root function.
  • No import.

Keep the line number = float(input('Number: ')) and the two print lines unchanged. The checker will type the other numbers.
