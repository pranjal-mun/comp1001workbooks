How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 and 5 covered: variables, assignment, the arithmetic operators, round(), and the math module. There are no hints in the code box. Plan the steps on paper first, then write the program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Each problem starts with its values already assigned at the top of the program. Keep those lines exactly as they are: Check runs your program several times, swapping in different values each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program with the given values and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Sum of the Digits

The program starts with a four-digit integer in number. Print the four digits added together, and their sum, on one line, like this for 3141:

3 + 1 + 4 + 1 = 9

Take the number apart with // and %: 3141 % 10 is the last digit, and 3141 // 10 is the number with the last digit removed. Do not turn the number into text. The + and = signs are text that print() displays between the values.

numberOutput
31413 + 1 + 4 + 1 = 9
90759 + 0 + 7 + 5 = 21
10001 + 0 + 0 + 0 = 1
20262 + 0 + 2 + 6 = 10
Rules the checker enforces
  • Take the digits apart with // and %.
  • Do not convert the number to text: no str().
  • No if statements.
  • Print everything on one line with a single print() call.

Keep the line number = 3141 as given: the checker swaps in the other numbers.

The program starts with the change owed, in cents, in cents. Print how many of each coin the machine should give, one coin per line, largest coin first, in exactly this layout:

Toonies: 6
Loonies: 0

🐉 Boss 3: Sort Three Integers

The program starts with three integers in a, b, and c. Print them on one line from smallest to largest, separated by spaces.

Python has two built-in functions for this kind of job: min(a, b, c) returns the smallest of the values and max(a, b, c) the largest. Call them the way you call round(). That leaves the middle value, and there is a trick: the three values add up to smallest + middle + largest, so subtracting the two you already know from the total leaves the middle one. No sorting and no if statements are needed.

a, b, cOutput
17, 4, 94 9 17
3, 8, 33 3 8
-2, 10, 0-2 0 10
5, 5, 55 5 5
Rules the checker enforces
  • Use min() for the smallest value and max() for the largest.
  • No if statements and no sorting.
  • Print all three values on one line with a single print() call.

Keep the three assignment lines as given: the checker swaps in the other values.

💀 Boss 4: Distance Between Two Points on Earth

The Earth is curved, so the distance between two places is not a straight line. If one place is at latitude t1 and longitude g1, and the other at t2 and g2, the distance along the surface, in kilometres, is

d = 6371.01 × arccos(sin t1 × sin t2 + cos t1 × cos t2 × cos(g1 − g2))

where 6371.01 is the average radius of the Earth in kilometres.

The program starts with the two places in degrees: lat1 and lon1 are St. John's, lat2 and lon2 the other city. Print the distance rounded to one decimal place.

Degrees in, radians expected

The trigonometric functions in the math module work in radians, not degrees. Convert every angle with math.radians() first. The inverse cosine is math.acos().

  • Round with round(..., 1) and print only the distance.
