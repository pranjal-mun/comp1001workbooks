2. Three division operators

Python separates division into three operations.

  • / gives the division result and produces a float for the numeric types used here.
  • // gives the floor quotient: the quotient rounded down to a whole number. With positive integers, it counts complete groups.
  • % gives the remainder left after those complete groups. It does not calculate a percentage.

For positive values, 17 objects form 3 complete groups of 5, with 2 left over. The values fit together: 17 = 3 × 5 + 2. For integers a and nonzero b, the general relationship is

a = (a // b) * b + (a % b).

Do not divide by zero with /, //, or %.

Negative values

Flooring and truncating differ for negative values: -7 // 2 is -4, because rounding down from −3.5 moves toward the smaller number −4. Our grouping problems use nonnegative counts and positive group sizes.

Example: Converting minutes

Other uses of the remainder

For a nonnegative integer n, n % 2 is 0 for an even number and 1 for an odd number. A remainder of 0 after division by a positive integer k means that n is divisible by k. We will use these facts in later decision programs.

Remainders also wrap a count back into a fixed range. On a clock numbered 0 through 11, (10 + 5) % 12 gives 3: advance five hours from 10 and wrap past 11. The 0 label represents the usual 12 on a clock face.

3. Precedence and parentheses

Python follows an order of operations called precedence:

  1. evaluate expressions inside parentheses;
  2. evaluate powers, **;
  3. evaluate *, /, //, and %, from left to right;
  4. evaluate + and -, from left to right.

In the first line, multiply 3 × 4 before adding 2. In the second, add 2 + 3 before multiplying by 4. Parentheses override the usual order and make an expression easier to read. For an average, (a + b) / 2 becomes (a + b) / 2; a + b / 2 divides only b by 2.

Powers need care

Consecutive powers group from the right: 2 ** 3 ** 2 means 2 ** (3 ** 2), giving 512. A leading minus needs care: -3 ** 2 means -(3 ** 2), giving −9; (-3) ** 2 gives 9. Use parentheses to make the intended base clear. Every opening parenthesis must have a matching closing parenthesis in the right order.

4. Mixing int and float

An arithmetic operation on an int and a float normally produces a float. That float then carries into the next arithmetic operation.

The / operator produces a float even when the mathematical answer is whole. Floor division does not guarantee an int: 7.0 // 2 gives 3.0. The value is whole, but its type is float. An explicit conversion can change the type later.

5. Converting numeric types

A function call asks a named operation to do its work. The values inside its parentheses are its arguments. A returned value can be stored or used in another expression. For example, int(3.9) returns 3. Conversion functions create a value of another type: int creates an integer, float creates a floating-point number, and str creates text.

The third printed line looks numeric, but str(42) returns a string. print does not display quotation marks around string contents. Numeric text must suit the conversion: int('42') works; int('3.5') is not a valid conversion to an integer.

int(3.9) truncates: it removes the fractional part, moving toward zero. It does not round to the nearest integer. For a negative value, int(-3.9) produces -3.

Rounding

Use round() when rounding is the goal.

With one argument, round returns the nearest integer for these values. The second argument requests a number of decimal places. Exactly halfway values round to the nearest even choice: round(2.5) gives 2 and round(3.5) gives 4.

Rounding a number does not specify how many digits print must show: print(round(3.0, 2)) displays 3.0, not two digits after the decimal point. Formatting numbers for display is part of Lecture 6.

6. Floating-point values

Computers store floating-point numbers in binary. Many ordinary decimal fractions have no exact finite binary representation, just as one third has no exact finite decimal representation. The stored value is an approximation.

This is a property of the number format, not a Python bug. Tiny errors can become visible after arithmetic. round can remove distracting digits from a result, but cannot make all earlier calculations exact. Because the stored input to rounding is approximate, even round(2.675, 2) gives 2.67.

Do not rely on exact equality

Do not rely on exact equality when comparing computed floats. The symbol == tests exact equality; the calculation 0.1 + 0.2 == 0.3 is false. A later lecture will teach comparison using a small tolerance. No comparison program is needed here.

7. Modules and import

A module contains reusable Python code, usually stored in a file. The standard library is the collection of modules supplied with Python. Its math module provides mathematical functions and constants. math.sqrt(x) returns the square root of a nonnegative number; math.pi provides an approximation to π.

The dot in math.sqrt shows where the name comes from. A namespace associates names with the values they refer to. The name sqrt belongs to the math namespace.

Python also permits a direct import:

This form places sqrt directly in the program's namespace. The course normally uses import math: a reader can see the function's source, and an unrelated local name sqrt does not replace math.sqrt. With a direct import, a later assignment sqrt = 5 replaces the imported name in the program. Qualified imports reduce name conflicts, but do not prevent every conflict: avoid assigning another value to math itself. Built-in functions such as int, float, str, and round need no import.

8. First do one case by hand

Before translating a calculation into Python, work through one concrete case on paper. Write the intermediate values. If the hand calculation is unclear, a plausible-looking Python expression will not repair the idea.

Suppose a floor uses tiles that are 20 centimetres wide. For a width of 95 centimetres:

  1. Four complete tiles cover 4 × 20 = 80 centimetres: 95 // 20 gives 4.
  2. There are 95 − 80 = 15 centimetres remaining: 95 % 20 gives 15.
  3. One more tile must be cut to cover that remaining width.

Only after the steps are clear should you write the expressions in a program. An exact fit is another useful case: 100 centimetres uses five complete tiles and leaves no remainder.
