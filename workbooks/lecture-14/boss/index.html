How bosses work

These problems use the for loop from Lecture 14: counting with range(), visiting the characters of a string, and building a result in a string or a counter. They use only what Lectures 4 to 14 covered: input() with int(), arithmetic including %, string indexing and find(), in, if, elif and else, and for loops. Test the smallest case, such as an empty string, as well as a typical case. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Keep the input lines exactly as the starter shows them: Check runs your program several times, typing a different sequence of answers each time, and every run must print exactly what the examples show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Forecast Conversion Table

Given two Celsius temperatures, start and end, print a conversion table from start through end in steps of 10. Each row contains the Celsius value and its Fahrenheit value, where F = C * 9 / 5 + 32.

Example 1
Input:
start = -20
end = 0

Output:
Celsius Fahrenheit
-20 -4.0
-10 14.0
0 32.0

Explanation:
The range visits -20, -10, and 0. The ending value is included.
Example 2
Input:
start = 30
end = 30

Output:
Celsius Fahrenheit
30 86.0

Explanation:
When start equals end, the table contains one row.
Constraints
  • -100 <= start <= end <= 100
  • start and end are multiples of 10.
  • Use one for loop with range().

The program reads start on the first line and end on the second, with no prompt.

  • Exactly one for loop and no while loop.
  • Give range() a start, a stop and a step of 10.
  • Keep the heading line Celsius Fahrenheit before the loop.
  • No import.

👾 Boss 2: Mirror Word Check

Given a string word, print Mirror word if it reads the same from left to right and from right to left. Otherwise, print Not a mirror word. Build the reversed string with a for loop and compare uppercase and lowercase characters exactly.

Example 1
Input:
word = "level"

Output:
Mirror word

Explanation:
Reversing "level" produces "level".
Example 2
Input:
word = ""

Output:
Mirror word

Explanation:
The reverse of the empty string is the empty string.
Constraints
  • 0 <= len(word) <= 100
  • word contains only English letters.
  • Do not use slicing to reverse the string.

The program reads word on one line, with no prompt.

  • Build the reversed string with the loop, not with slicing or reversed().
  • Compare the characters exactly: no lower() or upper().
  • Print exactly one line.
  • No import.

Keep the line word = input() unchanged. The checker will type the other words.

🐉 Boss 3: Sensor Parity Bit

Given a string bits, print the parity bit that makes the total number of 1 characters even. If bits does not contain exactly eight characters, or if any character is not 0 or 1, print Invalid data. Count the 1 characters with a for loop.

Example 1
Input:
bits = "10110010"

Output:
Parity bit: 0

Explanation:
The data contains four 1 characters, so the total is already even.
Example 2
Input:
bits = "00000001"

Output:
Parity bit: 1

Explanation:
The data contains one 1 character. Adding a parity bit of 1 makes the total two.
Example 3
Input:
bits = "1011"

Output:
Invalid data

Explanation:
The input does not contain eight characters.
Constraints
  • 0 <= len(bits) <= 20
  • bits contains no spaces.
  • Use one loop to validate the characters and count the 1 characters.

The program reads bits on one line, with no prompt.

  • Exactly one loop, and it is a for loop: it validates the characters and counts the 1 characters.

  • Test whether the count is even with % 2.
  • Print exactly one line.
  • No import.

💀 Boss 4: Shifted Course Note

Given a string message and an integer shift, replace each letter with the letter shift positions later in the alphabet. Wrap past z or Z. Preserve uppercase letters, lowercase letters, spaces, digits, and punctuation. A negative shift moves letters backward.

For each letter, find its position in the matching alphabet string, add shift, and use remainder after division by 26 to wrap the position. Build the answer in a string accumulator.

Example 1
Input:
message = "COMP 1001"
shift = 3

Output:
FRPS 1001

Explanation:
C becomes F, O becomes R, M becomes P, and P becomes S. Digits and spaces do not change.
Example 2
Input:
message = "abc XYZ"
shift = -3

Output:
xyz UVW

Explanation:
The negative shift moves each letter three positions backward and wraps a to x.
Example 3
Input:
message = ""
shift = 8

Output:
(an empty line)

Explanation:
The empty message produces an empty shifted message.
Constraints
  • 0 <= len(message) <= 100
  • -100 <= shift <= 100
  • message may contain English letters, digits, spaces, and punctuation.
  • Use a for loop and a string accumulator.

The program reads message on the first line and shift on the second, with no prompt.

  • Exactly one for loop and no while loop.

  • Wrap the new position with the remainder after division by 26.
  • Build the answer in the string accumulator shifted.
  • No import.

Keep the lines message = input() and shift = int(input()) unchanged. The checker will type the other pairs.
