The for Loop

1. The for Loop

A for loop repeats once for each item in a sequence.

  • The loop variable receives one item at the start of each pass.
  • The indented body runs for that item.
  • Python manages the next value. There is no separate update statement.

A First for Loop

Ranges

2. range(n)

range(n) supplies the whole numbers from 0 up to, but not including, n.

  • range(n) starts at 0.
  • It stops before n.
  • It supplies exactly n values when n is nonnegative.
  • range(0) supplies no values.

The stop value is exclusive: range(4) does not include 4. It supplies exactly four values, which makes it useful for repeating an action four times.

The loop variable does not have to appear in the body when only the repetition count matters.

3. range(start, stop)

The two-argument form is range(start, stop).

  • The first argument is included.
  • The stop argument is excluded.
  • With a step of 1, range(start, stop) supplies stop - start values.
  • To include 5, use a stop of 6.

The accumulator pattern has not changed. Only the loop control is shorter.

4. range(start, stop, step)

The three-argument form is range(start, stop, step). After each value, Python adds step to get the next one.

  • Python adds step after each value.
  • The next value would be 10, but 10 is the excluded stop value.
  • A step of 0 is not allowed.

5. Counting Backwards

Use a negative step when values should decrease.

  • A negative step counts backwards.
  • The stop value 0 is excluded. To include 0, use range(5, -1, -1).
  • The direction must move from the start toward the stop, so range(5, 0) supplies no values.

A positive step cannot move from 5 down toward 0.

Loop Control

6. Choosing a Loop

Use a for loop when the values or number of iterations are known before the loop starts. Use a while loop when repetition depends on a condition that changes during the run.

7. The Loop Variable

In for i in range(5):, the loop creates or reuses i and assigns the next range value at the start of each pass. Do not update it yourself.

  • The loop assigns 0, 1, and 2 to i.
  • Assigning 100 does not change the range.
  • The next pass overwrites 100 with the next range value.
  • Use a descriptive name such as number or position.

Assigning to a loop variable is legal, but usually confusing and ineffective. A name such as number, character, or position is clearer than a vague name when the variable's role matters.

Strings

8. Looping Over a String

A for loop can visit the characters of a string directly.

  • A string is a sequence of characters.
  • Direct looping gives the characters themselves.
  • An empty string causes zero iterations.
  • Direct looping cannot run past the end of the string.

9. Looping Over Indexes

Sometimes the position is needed. The valid indexes of a string are 0 through len(text) - 1. Therefore, range(len(text)) supplies exactly those indexes.

  • range(len(text)) gives every valid index.
  • Use indexes when the position is part of the task.
  • Use direct looping when only the character matters.

Start with the empty string. Initializing inside the loop would erase earlier characters. The empty string plays the same role as 0 in a sum: it is the starting value that adds no content.

Decisions and Patterns

  • Use for for a known sequence or count.
  • Use while when a condition or sentinel decides when to stop.
  • Loop directly over a string unless the position is needed.
  • Start a numeric counter at 0.
  • Start a string accumulator with the empty string.
  • Initialize before the loop and update inside the loop.
  • Test the empty sequence and both ends of a range.
