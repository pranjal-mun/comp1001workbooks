How bosses work

These problems use the parameters and return values from Lecture 18: the caller supplies the values as arguments, the function returns its result, and the caller prints it. They use only what Lectures 4 to 18 covered: input() with int() and float(), arithmetic, f-string formatting, comparisons combined with and and or, if statements, while and for loops, and string indexing and slicing. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Check also calls your function directly with more values and compares what it returns. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Keep the input lines exactly as the starter shows them: Check runs your program several times, typing a different sequence of answers each time, and every run must print exactly what the examples show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Diagonal length

Given the positive horizontal and vertical side lengths of a rectangle, produce its diagonal length to two decimal places. The diagonal joins opposite corners. Write diagonal(width, height) to return (width2 + height2)0.5. Read the two lengths on separate lines and print the returned result in the caller.

Example 1
Input:
8
15

Output:
17.00

Explanation:
The square root of 64 + 225 is 17.
Example 2
Input:
1
1

Output:
1.41

Explanation:
Equal unit sides give the square root of 2, rounded for display.
Constraints
  • Both inputs are numbers greater than 0 and at most 10000.
  • Both lengths use the same unit.
  • Use two parameters and return a numeric value; print only in the caller.

1, 11.41
3, 45.00

0.5, 1.21.30
2.5, 66.50
Rules the checker enforces
  • Define diagonal(width, height) with two parameters.
  • diagonal returns the length as a number. Check also calls it with (3.0, 4.0), (8.0, 15.0), (1.0, 1.0), and (0.5, 1.2).
  • Print only in the caller: diagonal prints nothing.

Keep the lines width = float(input()) and height = float(input()) unchanged. The checker will type the other lengths.

👾 Boss 2: Triangle check

Given three positive segment lengths, produce True if they can make a triangle and False otherwise. A triangle needs each pair of lengths to have a sum strictly greater than the remaining length. Write can_form_triangle(a, b, c) with a single Boolean return expression. Read the lengths on separate lines and print the result.

Example 1
Input:
4
6
7

Output:
True

Explanation:
Every pair has a sum greater than the remaining length.
Example 2
Input:
2
5
7

Output:
False

Explanation:
The first two lengths sum to 7; equality cannot form a triangle.
Constraints
  • Each length is a number greater than 0 and at most 10000.
  • All three lengths use the same unit.
  • Return one Boolean expression that combines the three strict comparisons.

The program reads the three lengths with float(input()) and no prompt.

TypedOutput
4, 6, 7True
2, 5, 7False
3, 4, 5True
1, 1, 2False
7, 2, 5False
5, 9, 4False
0.5, 0.5, 0.5True
Rules the checker enforces
  • Define can_form_triangle(a, b, c) with three parameters.
  • Return one Boolean expression: use a single return statement and no if.
  • can_form_triangle returns True or False. Check also calls it with every triple of whole-number lengths from 1 to 7.

🐉 Boss 3: Middle of three

Given three integers, produce the middle value when the three are placed in ascending order. Equal values keep their repeated positions; the middle of 5, 5, and 9 is 5. Write middle_value(a, b, c) using comparisons and several return statements. Read three integers on separate lines and print the result.

Example 1
Input:
14
3
8

Output:
8

Explanation:
Ascending order is 3, 8, 14, so the middle value is 8.
Example 2
Input:
5
5
9

Output:
5

Explanation:
The repeated value occupies the first two positions.
Constraints
  • Each integer is between -1000000 and 1000000 inclusive.
  • Repeated values are allowed.
  • Use comparisons and several returns; do not use sorting, lists, min, or max.

The program reads the three integers with int(input()) and no prompt.

TypedOutput
14, 3, 88
5, 5, 95
9, 5, 55
7, 7, 77
2, 1, 32
3, 2, 12
-1, -1, -2-1
-1000000, 1000000, 00
Rules the checker enforces
  • Define middle_value(a, b, c) with three parameters.
  • Do not use sorting, lists, min, or max.
  • Use several return statements.
  • middle_value returns the middle value. Check also calls it with every triple of integers from -2 to 2.

💀 Boss 4: Integer text check

Given one line of text, produce True if it represents an integer under these rules, or False otherwise. Ignore ordinary spaces at the beginning and end. The remaining text must contain one or more digits from 0 through 9, with an optional single + or - before them. Spaces between digits are invalid. Write is_integer_text(text) with several return paths, then read a line and print its result. Do not convert the text with int or float.

Example 1

The input has two spaces before -42 and two spaces after it.

Input:
  -42

Output:
True

Explanation:
Removing the outside spaces leaves a minus sign followed by two digits.
Example 2
Input:
+

Output:
False

Explanation:
A sign needs at least one digit after it.
Example 3
Input:


Output:
False

Explanation:
An empty line contains no digits.
Constraints
  • The input line contains 0 to 80 characters.
  • Characters may be ordinary spaces, ASCII letters, digits, punctuation, or signs.
  • Use string indexing, slicing, loops, and several return paths.
  • Return a Boolean on every path; avoid converting the input to a number.

  • Return True or False on every path. Check also calls is_integer_text with texts such as '007', '-', ' 12', '+-3', '9a', and '+0099'.
