Parameters and return values

Learning outcomes

The caller supplies arguments to a function's parameters. A returned value takes the place of the call, so the caller can use it in a calculation. Printing sends output to the screen.

  • Test missing-return paths and their boundaries.
  • Write functions that return Boolean results, including a search with a loop.

Arguments

1. Parameters and arguments

In L17, our functions often read their own input or used a fixed value. Now the caller can supply the value when it makes the call. A parameter is a name in the definition. An argument is a value supplied by a call.

In greet("Maya"), name gets "Maya". An argument can be a literal, a variable's value, or the result of an expression.

2. A function can send a result back

return volume gives the value 8 to the caller. The assignment stores it in answer. The final line displays it.

Calls and results, in time order

first = cube_volume(2)
second = cube_volume(10)
  1. cube_volume(2) returns 8, which is stored in first.
  2. cube_volume(10) returns 1000, which is stored in second.

3. Argument order and local parameter changes

Several arguments match by position. Python matches values from left to right.

For difference(20, 6), first receives 20 and second receives 6. difference(20, 6) returns 14. Reversing the arguments, difference(6, 20), returns -14.

Changing a parameter leaves the caller's name alone

The output is 5 10. The parameter n is a separate name. To use the returned value as the new value, write value = double(value).

Return flow

4. Returned values and early returns

A returned value takes the place of the call.

The expression square(4) + 1 becomes 16 + 1, then 17. The function can return an expression directly. Its caller can store the result, display it, compare it, or use it in another calculation.

A return ends the function immediately

The output is 5, then 3. For a negative input, the first return ends the call. Python never reaches the second one.

5. Returns in loops and alternative cases

A return inside a loop leaves the whole function.

The loop reaches "2", returns it, and stops scanning. The final return "" handles text with no digit, including an empty string.

Several returns can describe the alternatives

Each matching case answers and leaves. The final line covers scores below 50.

Output and None

6. Reaching the end gives back None

The banner appears on the screen. The assignment receives None, Python's special value for no result provided. A bare return also ends a function with the result None.

7. Printing and returning do different jobs

Screen: 16
Value stored in x: None

Screen: nothing
Value stored in y: 16

y + 1 is 17. Trying x + 1 raises TypeError. For a calculation, return its answer and let the caller choose what to display.

The screen output and the returned value travel separately

x = show_square(4) stores None in x. The displayed 16 belongs to the screen output. With y = square(4), the function returns 16 to the caller and sends nothing to the screen.

8. Missing-return paths

A missing return can leave one path unfinished.

When number < 0 is false, the function reaches its end and returns None.

Check both sides of a condition and its boundary. A successful test on the negative path would not have exposed the missing answer for other inputs.

10. Boolean results from loops

A loop can search for evidence.

has_digit("Room 2") gives True. has_digit("Room") gives False. has_digit("") gives False.

One digit is enough to return True. Return False only after checking every character. The final return lines up with for.

Final review

Supplying inputs and receiving a result

ParameterA name in a function definition. Each call gives it the corresponding argument's value.
ArgumentA value supplied by a call. Positional arguments match the parameters from left to right.
Local parameterAssigning to a parameter does not reassign the caller's variable. Our examples use numbers, strings, and Booleans.
return expressionComputes a value, ends the call, and gives the value to the caller. The value takes the place of the call in the caller's expression.
Early returnStops the whole function, including any loop that contains it. Later statements in the function do not run on that path.

Document the inputs and the promised result in the docstring. Keep input prompts and display choices with the caller when writing a calculation.

Output, None, and Boolean results

print(value)Displays output for a person. Printing inside a function does not send that printed value back as its result.
NoneThe result of reaching the end without a value-returning return, or executing a bare return. An output function may use this behavior intentionally.
Missing returnA bug when one path provides no result even though the function promises one. Test each path and the boundary between cases.
PredicateA function whose result is True or False. Use it directly in a condition, such as if is_even(n):.
TestsWrite expected results first. Check ordinary inputs, boundaries, and empty input where relevant. Verify returned values as well as screen output.
