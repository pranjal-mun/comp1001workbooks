How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 6 covered: input(), int() and float(), arithmetic with // and %, constants, and f-strings with format specifiers. Plan the steps on paper first, then write the program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Each problem starts with its input() lines already written. Keep the prompt text exactly as it is, because the prompt is part of the output that Check compares. input() returns text, so wrap each call in int() or float() before doing arithmetic. Check runs your program several times, typing different answers each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program with your own typed values and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Treat Plan

Oliver is on a treat plan: one treat on day 1, two on day 2, three on day 3, and so on. You are given a day number, days. Print the total number of treats he has eaten up to and including that day.

Read days with input() and print one line. The total of 1 + 2 + ... + n is n(n + 1) / 2, and one of the two factors is always even, so // leaves no remainder.

Example 1
Input: days = 7
Output: Oliver has eaten 28 treats by day 7.
Explanation: 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28.
Example 2
Input: days = 2
Output: Oliver has eaten 3 treats by day 2.
Constraints
  • 1 <= days <= 1000

The program reads the day after the prompt Days: .

Days: 7
Oliver has eaten 28 treats by day 7.

Rules the checker enforces
  • Convert the typed text with int().
  • Use the formula with //. The total must print as a whole number, not 28.0.
  • No loops.
  • Build the line with an f-string and print it with one print().

Keep the prompt 'Days: ' unchanged. The checker will type the other day numbers.

👾 Boss 2: Bottle Deposits

After the end-of-term party in EN2043, the 120 students of COMP 1001 leave behind a pile of drink containers. Ever Green Recycling pays $0.10 for a container that holds 1 litre or less and $0.25 for one that holds more. You are given the number of small containers, small, and large containers, large. Print the total refund with a dollar sign and two decimal places.

Read the two counts with input() and print one line.

Example 1
Input: small = 11, large = 3
Output: Refund: $1.85
Explanation: 11 * 0.10 + 3 * 0.25 = 1.85.
Example 2
Input: small = 0, large = 0
Output: Refund: $0.00
Constraints
  • 0 <= small <= 1000
  • 0 <= large <= 1000

The program reads the counts after the prompts Small containers: and Large containers: .

Small containers: 11
Large containers: 3
Refund: $1.85
TypedOutput
11 and 3Refund: $1.85
0 and 0Refund: $0.00
120 and 0Refund: $12.00
7 and 12Refund: $3.70
Rules the checker enforces
  • Convert both counts with int().
  • Store the two refund amounts, 0.10 and 0.25, in ALL_CAPS constants.
  • Format the refund with the .2f specifier. No round().
  • No if statements.
  • Build the line with an f-string and print it with one print().

Keep the two prompts unchanged. The checker will type the other counts.

🐉 Boss 3: Day-Old Bread

Manna Bakery in St. John's sells a loaf of bread for $3.49. Bread baked the day before is 60 percent off. You are given the number of day-old loaves, loaves. Print the regular price of that many loaves, the discount, and the total to pay, each as money with two decimal places followed by its label. Line the amounts up so the decimal points are in one column.

Read loaves with input() and print three lines. A width in the specifier does the lining up: {total:7.2f} shows two decimals, right aligned in seven characters, so smaller amounts get spaces on the left.

Example 1
Input: loaves = 3
Output:
$  10.47 regular price
$   6.28 discount
$   4.19 total
Explanation: 3 * 3.49 = 10.47. The discount is 60 percent of that. Each amount takes seven characters, so 10.47 gets two spaces in front and 6.28 gets three.
Example 2
Input: loaves = 100
Output:
$ 349.00 regular price
$ 209.40 discount
$ 139.60 total
Constraints
  • 1 <= loaves <= 1000

The program reads the count after the prompt Loaves: .

  • Convert the typed text with int().
  • Give each of the three amounts a width of 7 and two decimals, as in {total:7.2f}. No round().
  • Print exactly three lines, amount first and label after, with the decimal points in one column.
  • No if statements.
  • Build the lines with f-strings.

💀 Boss 4: Countdown to the Last Lecture

The screen at the front of EN2043 shows the time left until the last COMP 1001 lecture as one big number of seconds. You are given that number, seconds. Print it as days, hours, minutes, and seconds in the form D:HH:MM:SS. Hours, minutes, and seconds always take two digits, with a leading zero when needed. Days take as many digits as they need.

Read seconds with input() and print one line.

Example 1
Input: seconds = 93784
Output: 1:02:03:04
Explanation: 93784 = 86400 + 2 * 3600 + 3 * 60 + 4.
Example 2
Input: seconds = 59
Output: 0:00:00:59
Constraints
  • 0 <= seconds <= 10000000

  • Split the seconds with // and %.
  • Pad the hours, minutes, and seconds with the 02d specifier. No str() and no padding by hand.
  • No if statements.
  • Build the line with an f-string and print it with one print().

Keep the prompt 'Seconds: ' unchanged. The checker will type the other values.
