How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 6 covered: input(), int() and float(), arithmetic with // and %, constants, and f-strings with format specifiers. There are no hints in the code box. Plan the steps on paper first, then write the program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Each problem starts with its input() lines already written. Keep the prompt text exactly as it is, because the prompt is part of the output that Check compares. input() returns text, so wrap each call in int() or float() before doing arithmetic. Check runs your program several times, typing different answers each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program with your own typed values and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Treat Plan

Oliver is on a treat plan. He gets one treat on day 1, two treats on day 2, three on day 3, and so on. By day 7 he has eaten 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28 treats.

Read the day number from the keyboard and print the total number of treats up to and including that day, in this format:

Days: 7
Oliver has eaten 28 treats by day 7.

There is a formula for this sum. The total of 1 + 2 + ... + n is n(n + 1) / 2. Since one of n and n + 1 is always even, the division has no remainder, so use // and the result stays a whole number. A total of 28.0 is wrong.

TypedOutput
7Oliver has eaten 28 treats by day 7.
2Oliver has eaten 3 treats by day 2.
30Oliver has eaten 465 treats by day 30.
120Oliver has eaten 7260 treats by day 120.
Rules the checker enforces
  • Convert the typed text with int().
  • Use the formula with //. The total must print as a whole number, not 28.0.
  • No loops.
  • Build the line with an f-string and print it with one print().

Keep the prompt 'Days: ' unchanged. The checker will type the other day numbers.

👾 Boss 2: Bottle Deposits

After the end-of-term party in EN2043, the 120 students of COMP 1001 leave behind a pile of drink containers. Ever Green Recycling pays a refund for each container: $0.10 for a container that holds 1 litre or less, and $0.25 for a container that holds more than 1 litre.

Read the number of small containers and the number of large containers from the keyboard, then print the total refund as money, with a dollar sign and exactly two decimal places:

Small containers: 11
Large containers: 3
Refund: $1.85

The two refund amounts do not change, so store them in constants at the top of the program. The dollar sign is ordinary text in front of the braces, and the .2f specifier inside the braces takes care of the two decimals. Do not round the value: formatting changes the display, not the number.

TypedOutput
11 and 3Refund: $1.85
0 and 0Refund: $0.00
120 and 0Refund: $12.00
7 and 12Refund: $3.70
Rules the checker enforces
  • Convert both counts with int().
  • Store the two refund amounts, 0.10 and 0.25, in ALL_CAPS constants.
  • Format the refund with the .2f specifier. No round().
  • No if statements.
  • Build the line with an f-string and print it with one print().

Keep the two prompts unchanged. The checker will type the other counts.

🐉 Boss 3: Day-Old Bread

Manna Bakery in St. John's sells a loaf of bread for $3.49. Bread baked the day before is sold at a 60 percent discount.

Read the number of day-old loaves being bought from the keyboard. Then print the regular price of that many loaves, the discount, and the total to pay. Show every amount as money with two decimal places, and line the amounts up so that the dollar signs are in one column and the decimal points are in another:

Loaves: 3
Regular price: $  10.47
Discount:      $   6.28
Total:         $   4.19

A width in the specifier does the lining up. {total:7.2f} displays the value with two decimals, right aligned in a field seven characters wide. Use the same width for all three amounts, and make the three labels the same length, so the dollar signs and the decimal points land in the same columns on every line.

TypedRegular priceDiscountTotal
3$ 10.47$ 6.28$ 4.19
1$ 3.49$ 2.09$ 1.40
12$ 41.88$ 25.13$ 16.75
100$ 349.00$ 209.40$ 139.60
Rules the checker enforces
  • Convert the typed text with int().
  • Give each of the three amounts a width and two decimals, as in {total:7.2f}. No round().
  • Print exactly three lines, with the dollar signs in one column and the decimal points in one column.
  • No if statements.
  • Build the lines with f-strings.

Keep the prompt 'Loaves: ' unchanged. The checker will type the other counts.

💀 Boss 4: Countdown to the Last Lecture

The screen at the front of EN2043 shows how long is left until the last COMP 1001 lecture, but it shows the time as one big number of seconds. Nobody can read 93784 seconds at a glance.

Read the number of seconds from the keyboard and print it as days, hours, minutes, and seconds in the form D:HH:MM:SS. The hours, minutes, and seconds always take exactly two digits, with a leading zero when needed. The days take as many digits as they need.

Seconds: 93784
1:02:03:04

Work from the largest unit down. There are 86400 seconds in a day, so seconds // 86400 is the number of whole days and seconds % 86400 is what is left for the hours. Do the same with 3600 for the hours and 60 for the minutes. The 02d specifier pads a whole number to two digits with zeros, so {hours:02d} displays 2 as 02.

TypedOutput
937841:02:03:04
590:00:00:59
864001:00:00:00
100000011:13:46:40
Rules the checker enforces
  • Convert the typed text with int().
  • Split the seconds with // and %.
  • Pad the hours, minutes, and seconds with the 02d specifier. No str() and no padding by hand.
  • No if statements.
  • Build the line with an f-string and print it with one print().

Keep the prompt 'Seconds: ' unchanged. The checker will type the other values.
