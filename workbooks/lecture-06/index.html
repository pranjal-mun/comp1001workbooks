  • Processing calculates or transforms those values.

2. Controlling print()

print() can display several values in one call. By default it separates them with a space and ends the line with a newline.

The sep argument changes the separator placed between the values.

The end argument changes what is printed after the last value. The default is a newline.

4. Building Output with F-Strings

An f-string is a string literal with f before the opening quote. Any expression inside braces { } is evaluated and its value is placed into the text.

Text outside the braces is copied as written; the braces mark the parts that Python computes.

5. Format Specifiers

A colon inside the braces introduces a format specifier: {value:specifier}. The specifier controls how the value is displayed without changing the value itself.

SpecifierMeaningExample result
.2ftwo digits after the decimal point19.50
,.2fthousands separators and two decimals1,234.50
10.2fwidth 10, right aligned, two decimals 19.50
<10width 10, left alignedtext, then spaces
^10width 10, centredspaces on both sides
05dwidth 5, zero-padded integer00042

Money and Thousands Separators

Money is usually displayed with exactly two decimal places. A dollar sign is ordinary text placed before the braces.

A comma in the specifier inserts thousands separators.

7. Recognizing Legacy % Formatting

The textbook sometimes uses an older style in which % combines a format string with a value.

Course code uses an f-string for the same result.

Two meanings of %

Between a string and a value, % is legacy formatting. Between two numbers, % is the remainder operator. Recognize the legacy style when you read it, but write f-strings in your own programs.

8. Escape Sequences

An escape sequence is a backslash followed by a character. It stands for a character that is awkward to type directly inside a string literal.

SequenceMeaning
\nnewline
\ttab
\"a double quote inside a double-quoted string
\\one backslash

The gap produced by a tab depends on where the text is displayed, so fixed-width specifiers are more reliable for tables.
