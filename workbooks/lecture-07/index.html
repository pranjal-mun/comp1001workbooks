1. Strings Are Sequences

A string is text stored as an ordered sequence of characters. A character can be a letter, digit, space, punctuation mark, or other symbol. The characters stay in a fixed order.

Single and double quotation marks both create strings. The opening and closing marks must match. The quotes mark the boundaries; they are not characters in the stored value.

The function len() returns a string's number of characters. Spaces and punctuation count.

An empty string contains no characters. Write it as '' or ""; its length is zero.

2. Joining and Repeating Strings

For strings, the + operator means concatenation: joining strings end to end. It does not add numerical values.

The * operator repeats a string a whole number of times.

Python will not join a string and a number automatically. Use str() to create text from the number first. An f-string from Lecture 6 is also a good choice when the result is mainly output.

3. Character Positions and Indexes

An index is a character's position in a string. Python starts counting at zero, so index 0 refers to the first character.

positive012345
Python
negative-6-5-4-3-2-1

A negative index counts from the end. Index -1 is the last character, -2 is the second-last character, and so on.

For a string of length n, valid positive indexes run from 0 through n - 1. Valid negative indexes run from -1 through -n.

4. Indexes Must Be in Range

An index is in range when that character position exists. Asking for one character outside the valid range raises an IndexError.

Python reports an error similar to:

IndexError: string index out of range

The string has length 6, but its positive indexes stop at 5. A length is a count; an index is a position that starts at zero. Therefore, word[len(word)] is always one position too far for a non-empty string.

5. Slicing a String

A slice selects a run of characters. Write text[start:end]. The slice includes start but excludes end.

The slice word[0:3] takes indexes 0, 1, and 2. Index 3 is the boundary where the slice stops. The length of text[a:b] is normally b - a when both boundaries are in range and a <= b.

Omit start to begin at the first character. Omit end to continue through the last character.

Unlike indexing, slicing may use a boundary past the end. Python returns the available characters instead of raising an error. For example, word[3:20] is 'hon'.

A useful identity is text[:k] + text[k:] == text. The two slices meet at the same boundary without losing or repeating a character.

7. Methods Create New Strings

A method is an operation called with dot notation after a value. String methods return new values; they do not change the original string.

Useful methods for transforming text include:

  • .upper() returns an uppercase version;
  • .lower() returns a lowercase version;
  • .strip() removes whitespace from both ends; and
  • .replace(old, new) replaces every occurrence of old.

If you need to keep a method's result, assign it. Calling message.upper() on its own creates a value and then discards it.

8. Inspecting and Separating Text

Some operations report information about text rather than transforming it.

  • .find(part) returns the index where part first appears, or -1 when it is absent.
  • .count(part) returns the number of occurrences.
  • part in text returns True or False.

Use in when you need only yes or no. Use .find() when you need the first position. Always check a .find() result before using it as an index: -1 means “not found,” but it is also a valid negative index.

The method .split(separator) separates text into pieces. Python shows the pieces inside square brackets. This displayed value is a list; list operations are taught in a later lecture.

Without an argument, .split() separates at whitespace.

9. Looking at the Digits of a Number

An integer is not a string, so it has no character length or indexes. Use str() to create a string representation first.

The variable number still refers to an int. The variable digits refers to a new str. This is useful when the written digits matter more than their numerical value.
