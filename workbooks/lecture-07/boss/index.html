How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 7 covered: str() and len(), indexes and slices, + and * on strings, the methods .upper(), .lower(), .strip(), and .find(), and f-strings. Plan the steps on paper first, then write the program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Some problems start with their values already assigned at the top of the program; others read a value with input(). Keep those lines exactly as they are: Check runs your program several times, swapping in different values or typing different answers each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Digits as Characters

You are given a four-digit integer, number. Print its four digits added together, and their sum, on one line.

In Lecture 5 this job was done with // and %. This time treat the number as text: str(number) gives the string '3141', and an index picks out one character.

Example 1
Input: number = 3141
Output: 3 + 1 + 4 + 1 = 9
Example 2
Input: number = 1000
Output: 1 + 0 + 0 + 0 = 1
Constraints
  • 1000 <= number <= 9999
numberOutput
31413 + 1 + 4 + 1 = 9
86428 + 6 + 4 + 2 = 20
10001 + 0 + 0 + 0 = 1
20262 + 0 + 2 + 6 = 10
Rules the checker enforces
  • Keep number as an int. Make a text copy with str().
  • Pick out each digit with an index, as in digits[0].
  • No // and no %.
  • No if statements.
  • Print everything on one line with a single print().

Keep number = 3141 unchanged. The checker will replace it with the other numbers.

👾 Boss 2: Mailing Label

Memorial University's mailing address is 230 Elizabeth Avenue, St. John's, NL A1C 5S7. Canada Post asks for an address in capital letters, with the city, the province, two spaces, and then the postal code on the last line.

You are given the five parts of an address in name, street, city, province, and postal. Some of them are typed in lowercase. Print the label in capitals, then a line of dashes exactly as long as the address line.

Example 1
Input: name = 'Pranjal Patra', street = '230 Elizabeth Avenue',
       city = "St. John's", province = 'nl', postal = 'a1c 5s7'
Output:
PRANJAL PATRA
230 ELIZABETH AVENUE
ST. JOHN'S NL  A1C 5S7
----------------------
Explanation: The address line has 22 characters, so there are 22 dashes.
Example 2
Input: name = 'Sabina', street = '9 Whisker Way',
       city = 'gander', province = 'Nl', postal = 'a1v 1w8'
Output:
SABINA
9 WHISKER WAY
GANDER NL  A1V 1W8
------------------
Constraints
  • Every part is a non-empty string of letters, digits, spaces, and punctuation.
  • city may contain spaces, as in 'Corner Brook'.

  • Use .upper() for the capitals. Do not retype the values.
  • Make the dashes with '-' * len(...).
  • Put exactly two spaces between the province and the postal code.
  • No if statements.
  • Print four lines: name, street, address line, dashes.

Keep the five assignment lines unchanged. The checker will replace them with the other addresses.

🐉 Boss 3: MUN Email Address

Every new student and instructor at Memorial gets an email address. In this problem the username is the first letter of the first name followed by the whole last name, all in lowercase, at mun.ca. Pranjal Patra becomes ppatra@mun.ca.

You are given a full name, name: a first name, one space, and a last name. Print two lines: the initials, each capital followed by a full stop, and then the email address.

Example 1
Input: name = 'Pranjal Patra'
Output:
Initials: P.P.
Email: ppatra@mun.ca
Example 2
Input: name = 'grace hopper'
Output:
Initials: G.H.
Email: ghopper@mun.ca
Explanation: The name may be typed in lowercase. The initials are always capitals.
Constraints
  • name contains exactly one space, with at least one letter on each side of it.
  • The name is different in every run, so a fixed index like name[8] will not work.
nameOutput
'Pranjal Patra'Initials: P.P. / Email: ppatra@mun.ca
'Ada Lovelace'Initials: A.L. / Email: alovelace@mun.ca
'grace hopper'Initials: G.H. / Email: ghopper@mun.ca
'Oliver Poodle'Initials: O.P. / Email: opoodle@mun.ca
Rules the checker enforces
  • Find the space with .find(' '). No fixed index like name[8].
  • Cut the first and last names out with slices.
  • Use .upper() for the initials and .lower() for the address.
  • No .split(), .title(), or .capitalize(), and no if statements.
  • Print two lines: the initials, then the email address.

Keep name = 'Pranjal Patra' unchanged. The checker will replace it with the other names.

💀 Boss 4: Clean Up the Name

A sign-up form for COMP 1001 asks for a full name, and people often type extra spaces at the ends and capitals in the wrong places. ' pRANJAL patra ' should be treated as Pranjal Patra.

Read the name from the keyboard into raw. Fix it so that each of the two names starts with one capital and continues in lowercase. Print three lines: a greeting, a roster line with the last name in capitals, and the number of characters typed and the number kept. The characters kept are the two tidy names plus the one space between them.

Example 1
Input: raw = '  pRANJAL patra '
Output:
Hello, Pranjal Patra!
Roster: PATRA, Pranjal
Typed 16 characters, kept 13.
Explanation: 'Pranjal Patra' is 13 characters. The three outer spaces are dropped.
Example 2
Input: raw = 'SABINA cat '
Output:
Hello, Sabina Cat!
Roster: CAT, Sabina
Typed 11 characters, kept 10.
Constraints
  • raw has a first name, exactly one space, and a last name, with zero or more spaces at either end.
  • Each name has at least one letter.

The program reads the name after the prompt Name: .
