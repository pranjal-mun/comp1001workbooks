How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 7 covered: str() and len(), indexes and slices, + and * on strings, the methods .upper(), .lower(), .strip(), and .find(), and f-strings. There are no hints in the code box. Plan the steps on paper first, then write the program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Some problems start with their values already assigned at the top of the program; others read a value with input(). Keep those lines exactly as they are: Check runs your program several times, swapping in different values or typing different answers each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Digits as Characters

The program starts with a four-digit integer in number. Print the four digits added together, and their sum, on one line, like this for 3141:

3 + 1 + 4 + 1 = 9

In Lecture 5 this job was done with // and %. This time treat the number as text. str(number) gives the string '3141', and an index picks out one character: '3141'[0] is '3'. Each character is a one-character string. Turn it back into a number with int() before adding. Adding the characters without converting joins them into '3141' instead.

numberOutput
31413 + 1 + 4 + 1 = 9
86428 + 6 + 4 + 2 = 20
10001 + 0 + 0 + 0 = 1
20262 + 0 + 2 + 6 = 10
Rules the checker enforces
  • Keep number as an int. Make a text copy with str().
  • Pick out each digit with an index, as in digits[0].
  • No // and no %.
  • No if statements.
  • Print everything on one line with a single print().

Keep number = 3141 unchanged. The checker will replace it with the other numbers.

👾 Boss 2: Mailing Label

Memorial University's mailing address is 230 Elizabeth Avenue, St. John's, NL A1C 5S7. Canada Post asks for an address in capital letters, with the city, the province, two spaces, and then the postal code on the last line.

The program starts with the five parts of an address in name, street, city, province, and postal. Some of them are typed in lowercase. Print the label in capitals, then a line of dashes exactly as long as the address line:

PRANJAL PATRA
230 ELIZABETH AVENUE
ST. JOHN'S NL  A1C 5S7
----------------------

Use .upper() to make the capitals. Build the third line by joining the parts with +, then use len() on it and repeat '-' that many times with *. Every method returns a new string. The five variables at the top keep their original text.

Rules the checker enforces
  • Use .upper() for the capitals. Do not retype the values.
  • Make the dashes with '-' * len(...).
  • Put exactly two spaces between the province and the postal code.
  • No if statements.
  • Print four lines: name, street, address line, dashes.

Keep the five assignment lines unchanged. The checker will replace them with the other addresses.

🐉 Boss 3: MUN Email Address

Every new student and instructor at Memorial gets an email address. In this problem the username is the first letter of the first name followed by the whole last name, all in lowercase, at mun.ca. Pranjal Patra becomes ppatra@mun.ca.

The program starts with a full name in name: a first name, one space, and a last name. Print the initials, each capital followed by a full stop, and then the email address:

Initials: P.P.
Email: ppatra@mun.ca

The name is different in every run. Do not use a fixed index. name.find(' ') returns the index of the space. The slice name[:space] stops just before it and gives the first name; name[space + 1:] starts just after it and gives the last name. In one run the name is typed in lowercase. Use .upper() for the initials and .lower() for the address.

nameOutput
'Pranjal Patra'Initials: P.P. / Email: ppatra@mun.ca
'Ada Lovelace'Initials: A.L. / Email: alovelace@mun.ca
'grace hopper'Initials: G.H. / Email: ghopper@mun.ca
'Oliver Poodle'Initials: O.P. / Email: opoodle@mun.ca
Rules the checker enforces
  • Find the space with .find(' '). No fixed index like name[8].
  • Cut the first and last names out with slices.
  • Use .upper() for the initials and .lower() for the address.
  • No .split(), .title(), or .capitalize(), and no if statements.
  • Print two lines: the initials, then the email address.

Keep name = 'Pranjal Patra' unchanged. The checker will replace it with the other names.

💀 Boss 4: Clean Up the Name

A sign-up form for COMP 1001 asks for a full name, and people often type extra spaces at the ends and capitals in the wrong places. ' pRANJAL patra ' should be treated as Pranjal Patra.

Read the name from the keyboard into raw. Fix it so that each of the two names starts with one capital and continues in lowercase. Then print a greeting, a roster line with the last name in capitals, and a count of the characters typed and the characters kept:

Name:   pRANJAL patra 
Hello, Pranjal Patra!
Roster: PATRA, Pranjal
Typed 16 characters, kept 13.

Start with .strip() to remove the outer spaces, and store the result under a new name. A string cannot be changed in place, and the checker looks at raw afterwards to make sure it is still exactly what was typed. Then use .find(' ') and slices to separate the first name from the last name, and rebuild each one as its first character in .upper() plus the rest in .lower(). The characters kept are the two tidy names plus the one space between them.

TypedOutput
' pRANJAL patra 'Hello, Pranjal Patra! / Roster: PATRA, Pranjal / Typed 16 characters, kept 13.
'ada LOVELACE 'Hello, Ada Lovelace! / Roster: LOVELACE, Ada / Typed 14 characters, kept 12.
' oliver poodle'Hello, Oliver Poodle! / Roster: POODLE, Oliver / Typed 14 characters, kept 13.
'SABINA cat 'Hello, Sabina Cat! / Roster: CAT, Sabina / Typed 11 characters, kept 10.
Rules the checker enforces
  • Remove the outer spaces with .strip(), and keep raw exactly as typed.
  • Find the space with .find(' ') and cut the names apart with slices.
  • Fix the capitals with .upper() and .lower(). No .title(), .capitalize(), or .split().
  • Count the characters with len().
  • No if statements.
  • Print three lines: the greeting, the roster line, and the character counts.

Keep the line raw = input('Name: ') unchanged. The checker will type the other names, spaces included.
