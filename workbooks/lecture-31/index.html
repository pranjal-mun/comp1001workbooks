How the validation loop runs

  1. while True repeats the loop body until break runs.
  2. If int raises ValueError, control jumps to the except block. The loop asks again.
  3. If int succeeds, break ends the loop.
  4. After the loop, mark is always a whole number.

def main():

The two operations accept different inputs. Notice that int accepts "-5" and " 7 " even though isdigit returns False.

  • Use try when other code, such as int or float, decides what fails.
  • Use if for a rule that you write yourself, such as a range.

Review

A validation function and loop

def to_mark(text):
    """Return text as a mark from 0 to 100.

    Raise ValueError if it is not one.
    """
    mark = int(text)
    if mark < 0 or mark > 100:
        raise ValueError("mark out of range")
    return mark

def main():
    while True:
        try:
            mark = to_mark(input("Mark: "))
            break
        except ValueError:
            print("Enter a mark from 0 to 100.")

The function

  • Converts the text and checks the rule.
  • Raises ValueError for a bad value.
  • Does not use input or print.

The loop

  • Calls the function inside try.
  • Uses break when the value is valid.
  • Prints a message in the except ValueError block, then asks again.

Reading many values

def main():
    marks = []
    while True:
        text = input("Mark: ").strip()
        if text == "":
            break
        try:
            marks.append(to_mark(text))
        except ValueError:
            print(f"Not saved: {text}")
    if len(marks) == 0:
        print("No marks.")
        return
    average = sum(marks) / len(marks)
    print(f"Average: {average:.1f}")

Rules

  • Check for the blank line before you convert.
  • Save a value only when the function returns it.
  • A bad entry gets a message. The loop goes on.
  • Check for the empty list before you divide.
  • Use try for int and float. Use if for a range.
  • Test boundary values and bad input.
