Lecture 15 Boss Problems

Nested loops, break and continue

Pranjal Patra
Department of Computer Science, Memorial University of Newfoundland

How bosses work

These problems use the ideas from Lecture 15: nested loops for rows and columns, break to leave the nearest loop, and continue to skip the rest of one pass. They use only what Lectures 4 to 15 covered: input() with int(), arithmetic including % and //, f-strings with a field width, string indexing and lower(), if, elif and else, while loops, and for loops with range(). Test the smallest case, such as a size of 1 or an empty line, as well as a typical case. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its value with a plain input() that shows no prompt, so the output is only what your program prints. Keep the input line exactly as the starter shows it: Check runs your program several times, typing a different value each time, and every run must print exactly what the examples show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Course Product Grid

Given an integer size, produce a multiplication grid with row and column labels from 1 through size. A multiplication grid places the product of its row label and column label in each cell. Give every label and product a field width of four characters.

Example 1
Input:
size = 3

Output:
       1   2   3
   1   1   2   3
   2   2   4   6
   3   3   6   9

Explanation:
The row labelled 2 contains 2 times 1, 2 times 2, and 2 times 3.
Example 2
Input:
size = 1

Output:
       1
   1   1

Explanation:
A size of 1 produces one labelled row and one labelled column.
Constraints
  • 1 <= size <= 9
  • Print the top labels before the body of the grid.
  • Use nested loops for the products.

The program reads size on one line, with no prompt. The top-left corner of the grid is four spaces.

3
       1   2   3
   1   1   2   3
   2   2   4   6
   3   3   6   9
TypedOutput
3the label line and three rows, as in Example 1
1the two lines in Example 2
9the label line, then nine rows; the last row holds the label 9 and the products 9 through 81
5the label line, then five rows; the last row holds the label 5 and the products 5 through 25
2the label line with 1 and 2, then the rows 1, 1, 2 and 2, 2, 4, every value in a field four characters wide
Rules the checker enforces
  • Nested for loops: an inner for loop inside the body of an outer one.
  • No while loop.
  • Give every label and product a field width of four with :4.
  • No import.

Keep the line size = int(input()) unchanged. The checker will type the other sizes.

👾 Boss 2: Lab Station Binary Label

Given a non-negative decimal integer number, produce its binary representation. Decimal is the usual base-10 notation. Binary is base 2 and uses only the digits 0 and 1. Repeatedly take the remainder after division by 2 and add that digit to the beginning of the result. Use while True and one break.

Example 1
Input:
number = 13

Output:
1101

Explanation:
The remainders are found from right to left, so each new digit is added to the
beginning of the result.
Example 2
Input:
number = 0

Output:
0

Explanation:
The loop runs once before it checks whether the quotient has reached zero.
Constraints
  • 0 <= number <= 1023
  • Use integer division and remainder.
  • Use while True with one clear break.

The program reads number on one line, with no prompt. The starter holds a placeholder break so that it runs; replace the comment and the placeholder with your loop body, keeping one break.

13
1101
TypedOutput
131101
00
10231111111111
11
210
81000
25511111111
5121000000000
Rules the checker enforces
  • Use while True for the loop.
  • Leave the loop with exactly one break.
  • Find each digit with % 2 and move on with // 2.
  • Build the digits with the loop; bin() and format codes are not allowed.
  • Print exactly one line.
  • No import.

Keep the line number = int(input()) unchanged. The checker will type the other numbers.

🐉 Boss 3: Phrase Mirror Check

Given a phrase, produce Palindrome when its letters read the same from left to right and right to left after spaces, commas, periods, exclamation marks, and question marks are ignored. Uppercase and lowercase letters count as equal. Otherwise, produce Not a palindrome. A palindrome is text that reads the same in both directions under these rules.

Example 1
Input:
phrase = "Never odd or even!"

Output:
Palindrome

Explanation:
Ignoring spaces, the exclamation mark, and letter case gives neveroddoreven.
That text reads the same in both directions.
Example 2
Input:
phrase = "Hello, MUN!"

Output:
Not a palindrome

Explanation:
The cleaned text hellomun does not read the same in both directions.
Example 3
Input:
phrase = ""

Output:
Palindrome

Explanation:
The empty phrase has no mismatched pair of letters.
Constraints
  • 0 <= len(phrase) <= 80
  • The phrase contains letters, spaces, commas, periods, exclamation marks, or question marks.
  • Use continue while cleaning the phrase.
  • Use break when a mismatched pair is found.

The program reads phrase on one line, with no prompt.

💀 Boss 4: Prime Roll Call

Given an integer limit, produce every prime number from 2 through limit, one per line. A prime number is an integer greater than 1 that has no divisor other than 1 and itself. If the range contains no primes, produce No primes. For each candidate, use an inner loop to test possible divisors. A divisor leaves a remainder of zero.

Example 1
Input:
limit = 10

Output:
2
3
5
7

Explanation:
Each printed number has no divisor from 2 up to one less than itself.
Example 2
Input:
limit = 1

Output:
No primes

Explanation:
There is no integer from 2 through 1, so no prime is printed.
Constraints
  • 1 <= limit <= 200
  • Use an outer loop for candidate numbers.
  • Use an inner loop and break when a divisor is found.
  • The inner break must not stop the outer loop.

The program reads limit on one line, with no prompt.

10
2
3
5
7

200the 46 primes from 2 to 199, one per line
Rules the checker enforces
  • Nested for loops: an inner for loop inside the body of an outer one.
  • Leave the divisor loop with break as soon as a divisor is found.
  • Recognise a divisor by a remainder of zero with %.
  • No while loop.
  • No import.

Keep the line limit = int(input()) unchanged. The checker will type the other limits.
