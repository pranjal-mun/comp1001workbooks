Nested Loops

1. A nested loop is a loop inside a loop

A nested loop is a loop in the body of another loop. The loop on the outside is the outer loop. The loop inside it is the inner loop.

For row = 0, the inner loop runs completely through columns 0 to 3. Then row becomes 1 and the inner loop starts again from column 0.

3. Multiply the iteration counts

If the outer loop makes 3 passes and the inner loop makes 4 passes each time, the inner body runs:

3 outer passes x 4 inner passes = 12 executions

For fixed ranges, multiply rather than add.

Nested loops can grow quickly. Two loops that each make 100 passes execute the inner body 10,000 times.

Rows and Columns

4. Think of the loops as rows and columns

The outer loop often selects a row. The inner loop moves across the columns in that row.

end="" prevents each star from starting a new line. The empty print() is after the inner loop but inside the outer loop. It moves to the next line once the row is complete.

Indentation gives the two print statements different jobs:

  • print("*", end="") runs once per column.
  • print() runs once per row.

6. The inner range can depend on the outer value

The inner loop does not have to make the same number of passes for every row. Its range can use the current outer value.

On row 1, range(row) supplies one value. On row 5, it supplies five. The number of inner passes is 1 + 2 + 3 + 4 + 5, not 5 × 5.

7. Nested loops can visit every pair

To produce every pair without pairing an item with itself, start the inner loop just after the outer position.

When first is 0, the inner loop uses positions 1 and 2. When first is 1, it uses position 2. When first is 2, the inner range is empty.

Starting at first + 1 prevents A A and avoids printing both A B and B A.

break

8. break leaves a loop immediately

break ends the nearest loop and continues with the first statement after that loop.

When number is 6, its square is greater than 30, so break runs before 6 is printed.

A useful break has one clear meaning, such as ending a sentinel loop or stopping a search after a match. Several exits hidden inside branches make a loop difficult to trace.

9. break affects only the innermost loop

Inside nested loops, break leaves the loop that directly contains it. The outer loop continues with its next pass.

The inner loop stops at column 3 on every row. The outer loop still reaches all three row values.

continue

10. continue skips the rest of one pass

continue skips the remaining statements in the current iteration and begins the next iteration of the nearest loop. It does not end the loop.

The values 3, 6, and 9 reach continue, so the print statement is skipped for those passes.

Use continue when a simple condition near the top can discard a case and leave the main work less deeply indented.

11. continue can hide a while-loop update

In a for loop, Python automatically gets the next value. In a while loop, the programmer normally writes the update. A continue can skip an update that appears later in the body.

This program becomes infinite when number reaches 5:

number = 0
while number < 10:
    if number == 5:
        continue
    print(number)
    number = number + 1

This listing has no Run button. A code box on this page stops a program that is still running after a few seconds and reports a timeout, which is how an infinite loop shows up here.

At 5, continue returns to the condition. The update is skipped, so number remains 5 forever. A safer repair moves the update before the possible continue or rewrites the condition so continue is unnecessary.

Before using break or continue, ask:
  • Is the jump easy to see and explain?
  • Can the loop still be hand-traced?
  • In a while loop, does every continuing path still update the control value?
  • In nested loops, am I clear about which loop is affected?

Design a program that prints the seat numbers for a theatre with three rows of five seats. Seat 3 is reserved in every row, so the program skips it. In row 2, a barrier before seat 5 ends the row early. Start with the conversation, then work through the six problem-solving stages.

Storyboards

1. Understand

  • Input: none. The theatre always has 3 rows of 5 seats.
  • Output: one line per row, with the row label and then the seat numbers.
  • Seat 3 never prints.
  • Row 2 stops before seat 5. Rows 1 and 3 print every seat except seat 3.

2. Decompose

  1. Visit each row.
  2. Print the row label.
  3. Visit each seat in that row.
  4. End the row at the barrier.
  5. Skip the reserved seat.
  6. Print the seat number on the same line.
  7. After the seats, end the line.

Summary

  • For each outer value, the inner loop goes through all of its values.
  • Fixed counts: inner-body runs = outer passes × inner passes.
  • end="" keeps several values on the same row.
  • break ends the nearest loop; inside an inner loop, only the inner loop.
  • continue skips to the next iteration of the nearest loop.
