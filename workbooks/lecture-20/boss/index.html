How bosses work

These problems use stepwise refinement and the scope rules from Lecture 20:

  • a main() that calls named helpers
  • helpers that receive their inputs as parameters and return one value
  • fixed values in uppercase global constants
  • changing data kept local to functions

They use only what Lectures 4 to 20 covered:

  • input() with int() and float()
  • arithmetic, including // and %
  • comparisons, if statements, while and for loops
  • strings and the random module
  • functions

Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Check also calls your functions directly with more values and compares what they return. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show. In Problem 3 the seed makes the random choices repeatable, so a given seed always produces the same password.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Distance fare

A taxi charges a base fare of $3.50 plus $0.40 for every 200 metres. A part of 200 metres is charged in proportion, so 100 metres costs $0.20. One kilometre is 1000 metres.

Write a program that reads a trip distance in kilometres and prints the fare as shown in the examples. Write the function fare(kilometres). It takes the distance and returns the fare.

Store the three fixed pricing values in global constants. Keep the distance and the calculated fare in local variables inside functions.

Example 1
Input:
1.5
Output:
Fare: $6.50
Explanation:
1500 metres adds $3.00 to the $3.50 base amount.
Example 2
Input:
0
Output:
Fare: $3.50
Explanation:
A zero-distance trip has only the base amount.
Constraints
  • The input is a number from 0 through 1000 kilometres.
  • Use BASE_FARE, RATE_PER_SEGMENT, and METRES_PER_SEGMENT as constants.
  • Use fare, main, and the __name__ guard. Print two decimal places.

2.35Fare: $8.20

Rules the checker enforces
  • Keep the three constants from the starter, and use each of them in fare instead of writing its value again.
  • Define fare(kilometres) with one parameter. It returns the fare. Check also calls it with distances such as 0.2 and 1.
  • Keep changing data local: do not use global, and assign only uppercase constants at the top level.
  • Define main with empty parentheses and end the file with the standard guard.

👾 Boss 2: Measure description

For this exercise, 1 cup is 16 tablespoons and 1 tablespoon is 3 teaspoons.

Write a program that reads a whole-number quantity (0 or more) on the first line and a unit on the second line. The unit is cup, tablespoon or teaspoon. The program prints the same volume with as many cups as possible, then as many tablespoons as possible, then the teaspoons that are left.

Always print all three amounts in the format shown in the examples. Keep the plural labels (cups, tablespoons, teaspoons) even when an amount is 1. Write these functions:

  1. to_teaspoons(quantity, unit) returns the total number of teaspoons.
  2. describe(total) takes a number of teaspoons and returns the output line as a string.

Store the unit relationships in global constants.

Explanation:
48 teaspoons fill one cup; the remaining 22 fill seven tablespoons and leave one teaspoon.

Explanation:
Zero of any allowed unit gives zero in every output position.
Example 3
Input:
20
tablespoon
Output:
1 cups, 4 tablespoons, 0 teaspoons
Explanation:
Sixteen tablespoons fill one cup and four tablespoons remain.
Constraints
  • The quantity is a whole number from 0 through 10000.
  • The unit is exactly one of the three words listed above.
  • Use to_teaspoons, describe, main, and the __name__ guard.
  • Use integer division and remainder. Return one value from each calculation helper.

🐉 Boss 3: Password search

A seed is a number that starts the random generator from a repeatable state. The same seed always gives the same random choices.

Write a program that reads a whole-number seed and generates passwords until one is good. It prints the first good password and the number of attempts. A good password has:

  • at least 9 characters
  • at least one uppercase letter (A to Z)
  • at least one lowercase letter (a to z)
  • at least one digit (0 to 9)

Each attempt makes one password in two steps:

  1. Choose a length from 7 through 11 with random.randint.
  2. Choose that many characters, one at a time, with random.choice from ALLOWED. Keep ALLOWED exactly as it is in the starter code.

Write these functions:

  1. generate_password() makes one password and returns it.
  2. is_good_password(password) returns True when the password is good.
  3. main() reads the seed and sets it once. It then generates passwords until one is good.

Count every password you generate, including the good one. Keep the counter in a local variable.

Example 1
Input:
1
Output:
Password: EPyYngFb51
Attempts: 2
Explanation:
The seed fixes the generated candidates; the final candidate passes all four rules.
Example 2
Input:
0
Output:
Password: W4Acq9GFz6
Attempts: 1
Explanation:
The first candidate passes, so the attempt count is 1.
Constraints
  • The seed is a whole number from 0 through 1000000.
  • Use the exact ALLOWED string in the starter code.
  • Generate length before characters on every attempt. Stop at the first passing candidate.
  • Use loops, character comparisons, Boolean flags, functions, and the __name__ guard.
  • Use random.seed once in main. Use no changing global variables.

2Password: ZU3G8xI7CG, Attempts: 3

Rules the checker enforces
  • Keep import random and the ALLOWED string exactly as the starter gives them.
  • Define generate_password() with empty parentheses. It uses random.randint for the length and random.choice for each character, and returns the candidate. Check calls it many times and expects 7 to 11 characters from ALLOWED each time.
  • Define is_good_password(password). It returns True or False. Check also calls it with strings such as '', 'abc', 'Abcdefg2', and 'abcdefgh2'.
  • Call random.seed once, in main, before the search loop.
  • Keep changing data local: do not use global, and assign only uppercase constants at the top level.
  • Define main with empty parentheses and end the file with the standard guard.

💀 Boss 4: Base conversion

A base is the number of digit values a number system uses. Base 2 uses the digits 0 and 1. Base 16 uses 0 to 9 and then A to F, where A is 10 and F is 15.

The rightmost digit has place value 1. Each place to the left has a place value equal to the base times the place value on its right. For example, the place values in base 2 are 1, 2, 4, 8, and so on.

Write a program that reads three lines: the source base, the target base, and a number (0 or more) written in the source base. It prints the same number written in the target base.

  • Support bases 2 through 16.
  • If either base is outside that range, print Invalid base. and stop. Do not read the number.
  • When both bases are supported, the number text is always valid.
  • Print the result without leading zeros. Zero prints as 0.

Write these functions:

  1. digit_value(ch) returns the value of one digit symbol, for example 10 for A.
  2. to_decimal(text, base) returns the value of the number text as an integer.
  3. from_decimal(number, base) returns the number written in the given base, as a string.
  4. main() reads the input and prints the result.

Store the digit symbols in the constant DIGITS.

Example 1
Input:
12
5
2A
Output:
114
Explanation:
2A in base 12 is 2 times 12 plus 10, or 34. In base 5, 114 is 25 plus 5 plus 4, or 34.
Example 2
Input:

Output:
0
Explanation:
Leading zeros still represent zero.
Example 3
Input:

10
Output:

Explanation:
Base 1 is outside the supported range; no number text is read.
Constraints
  • Each base is a whole number. Supported bases are 2 through 16 inclusive.
  • For supported bases, the number has 1 through 12 characters from DIGITS[:source_base]. Use uppercase letters.
  • Use the named helpers, loops, and the __name__ guard.
  • Convert by place-value accumulation and repeated integer division. Do not use int(text, base), bin, oct, or hex.
  • Every helper returns one value. Keep changing data local.

  • Define digit_value(ch), to_decimal(text, base), and from_decimal(number, base). Each returns one value. Check calls digit_value with every symbol, to_decimal with values such as ('777', 8) and ('10', 3), and from_decimal with values such as (0, 2), (9, 3), and (16, 16).
  • to_decimal uses digit_value for each character.
  • Do not use int with a base argument, bin, oct, or hex.
  • Keep changing data local: do not use global, and assign only uppercase constants at the top level.
  • Define main with empty parentheses and end the file with the standard guard.
