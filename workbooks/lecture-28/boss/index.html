Lecture 28 Boss Problems

Selection sort and merge sort

Pranjal Patra
Department of Computer Science, Memorial University of Newfoundland

How bosses work

These problems use selection sort and merge sort from Lecture 28:

  • selection sort, which selects and swaps a value on each pass
  • the two-index merge of two sorted lists
  • recursive merge sort, and counting the value comparisons of each sort

They use only what Lectures 4 to 28 covered:

  • input() with int(), split(), and blank input lines
  • random.seed and random.randint
  • f-strings with field widths such as :4d and :>10
  • while and for loops, lists, slices, and functions that return a value, including recursive functions

Each problem names the functions to write. Write the rest of the program at the top level, after the functions. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show. Check also calls your functions directly with other lists.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Print a reproducible ticket

Write a program that reads an integer seed and makes a lottery ticket. A seed makes the random choices repeat when the program runs again. Print the six picks in their original order, then print the sorted ticket and a built-in sorting check.

  • Call random.seed(seed) before picking numbers.
  • Pick six different whole numbers from 1 to 49 with random.randint. Pick again when a number is already chosen.
  • Keep the picks in the order they were chosen.
  • Define selection_sort(values) with the selection sort algorithm from section 3 of the workbook. It changes its input list and returns nothing.
  • Sort a copy of the picks with that function. Do not use sort or sorted inside it.
  • Print the original picks, the sorted copy, and sorted(picks) on separate lines.
Example 1
Input:
11
Output:
[29, 36, 30, 33, 38, 13]
[13, 29, 30, 33, 36, 38]
[13, 29, 30, 33, 36, 38]
Explanation:
The last two lines show the same ascending ticket.
Example 2
Input:
0
Output:
[25, 49, 27, 3, 17, 33]
[3, 17, 25, 27, 33, 49]
[3, 17, 25, 27, 33, 49]
Explanation:
The seed can be zero. The picks still contain six different numbers.
Constraints
  • The input is one integer seed of 0 or more.
  • Each picked number is from 1 to 49, including both ends.
  • Use a loop, a membership test, and your own selection sort.
  • Keep picks unchanged when sorting the ticket. Read input without a prompt.

👾 Boss 2: Merge each value once

Write a program that reads two ascending lists and merges them without duplicates. Read each list from one line of whole numbers separated by spaces. A blank line represents an empty list. Print the merged list, then print its length on a separate line.

  • Define merge_unique(left, right). Return a new ascending list that contains each value once.
  • Keep both input lists unchanged.
  • Use the two-index merge method. Both input lists can contain repeated values.
  • Check for a repeated value before adding it, including values in the remaining slices.
  • Replace each remaining-slice extend with a loop. Use split() to read each input line.
Example 1
Input:
2 2 6
2 5 5 8
Output:
[2, 5, 6, 8]
4
Explanation:
The value 2 occurs in both lists. Repeated values enter the result once.
Example 2
Input:
(blank line)
4 4 9
Output:
[4, 9]
2
Explanation:
The empty left list needs no front-value comparisons.
Constraints
  • Each input line is blank or contains integers separated by spaces.
  • Each input list is in ascending order.
  • Use loops, indices, slices, and append.
  • Do not use sort or sorted in this program.

🐉 Boss 3: Count every selection comparison

Write a program that reads one integer per line until a blank line. Sort a copy in ascending order and a second copy in descending order. Print each list after every pass and report the value comparisons.

  • Define selection_sort_count(values) and selection_sort_desc_count(values). Each changes the list it receives.
  • Each function prints the list after every pass and returns only its comparison count.
  • Count one comparison whenever the inner loop compares two values. Use strict comparisons to select a value.
  • After the ascending passes, print Ascending comparisons: and the count.
  • Print Formula: and the value of n * (n - 1) // 2.
  • After the descending passes, print Descending comparisons: and the count.
  • Think about whether changing the input order changes the count. The model answer explains it.
Example 1
Input:
1
4
6
(blank line)
Output:
[1, 4, 6]
[1, 4, 6]
Ascending comparisons: 3
Formula: 3
[6, 4, 1]
[6, 4, 1]
Descending comparisons: 3
Explanation:
The ascending input still uses three comparisons. Each sort prints two passes.
Example 2
Input:

(blank line)
Output:
Ascending comparisons: 0
Formula: 0
Descending comparisons: 0
Explanation:
One element needs no passes and no comparisons.
Example 3
Input:
(blank line)
Output:
Ascending comparisons: 0
Formula: 0
Descending comparisons: 0
Explanation:
An empty list also needs no passes and no comparisons.
Constraints
  • Each nonblank input line contains an integer.
  • A blank line ends the input. It can be the first line.
  • Use selection sort in both functions. Do not use built-in sorting.
  • Return the count as one integer. Keep the original input list unchanged. Read input without prompts.

💀 Boss 4: Compare the comparisons of two sorts

Write a program that reads an integer seed and prints a comparison table for two sorts. Use list lengths 8, 16, and 32. For each length, build a new list of random whole numbers from 1 to 100. Print the length, selection sort count, and merge sort count in fixed-width columns.

  • Call random.seed(seed) once before building the three lists. Continue the same random sequence for all three.
  • Define merge and merge_sort as in sections 5 and 7 of the workbook. They keep their input lists unchanged.
  • Define merge_count(left, right) to run the same comparison loop as merge. Return only the number of value comparisons.
  • Define merge_sort_count(values). Return 0 for a base case.
  • Otherwise, add the two recursive counts. Use merge_count on merge_sort(left_part) and merge_sort(right_part) for the current merge.
  • The count covers the comparisons of one merge sort. Do not add the work of helper calls used to obtain the sorted parts.
  • Define selection_count(n) to return n * (n - 1) // 2.
  • Keep every input list unchanged. Each counting function returns one integer.
  • Use column widths 4, 10, and 8, with one space between columns. Right-align headings and values.
  • After the table, print sorted of the eight-element list on its own line.
  • Think about how the counts compare with the maximum counts in section 9 of the workbook. The model answer explains it.
Example 1
Input:
7
Output:
   n  Selection    Merge
   8         28       15
  16        120       46
  32        496      119
[7, 10, 13, 20, 42, 51, 69, 84]
Explanation:
The merge counts stay below the maximum for each length.
Example 2
Input:
0
Output:
   n  Selection    Merge
   8         28       17
  16        120       45
  32        496      121
[6, 34, 50, 52, 54, 63, 66, 98]
Explanation:
A zero seed is valid. The merge count for eight elements reaches the maximum of 17.
Constraints
  • The input is one integer seed of 0 or more.
  • Random values include both 1 and 100. Repeated values are allowed.
  • Count only comparisons between input values.
  • Use the stated recursive functions and return counts as single integers.
  • For lengths 8, 16, and 32, merge sort must use at most 17, 49, and 129 comparisons. Read input without a prompt.
