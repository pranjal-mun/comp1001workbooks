1. Sorting a list

Sorting puts the elements of a list in order. Ascending order puts smaller values first. The input [8, 3, 6, 3, 1] becomes [1, 3, 3, 6, 8].

The sorted list has the same elements. Both copies of 3 stay in the list.

2. Selection sort selects and swaps

Find the smallest value in the list. Swap it with the value at index 0.

The first position is complete. The next pass starts at index 1.

A swap exchanges the values at two indices.

Python reads both values on the right before it assigns either value on the left.

Index 0 gets 1. Index 3 gets 5.

The same list now contains the values in their new positions.

Merge

5. Merging two sorted lists

A merge combines two sorted lists into one sorted list. Compare the first unused value in each list.

After each comparison, advance the index of the list that supplied the value.

merge takes two ascending lists and returns a new ascending list.

i and j identify the next unused values. The loop runs while both indices are valid.

If the values are equal, the function takes the left value first.

When the loop ends, the two slices contain the unused values. At most one slice has elements.

extend adds each remaining value to the result.

Merge sort

7. Merge sort splits and combines

The function calls itself on each half. A list of length 0 or 1 is already in order.

The upper branches show splits. The lower branches show merges.

merge_sort returns a new ascending list. It keeps the input list unchanged.

The base case returns a copy of a list of length 0 or 1.

values[:mid] and values[mid:] cover separate parts of the list.

Each recursive call sorts one part. merge combines the two results after both calls return.

For an odd length, the right part has one extra element.

9. The cost of merge sort, comparisons and extra space

Each box shows the length of one merge result. Each merge writes every input element once to its result.

For eight elements, three merge levels give 24 writes. At each level, the parts do not overlap.

For a power of two, there are log2 n merge levels. The work grows in proportion to n log2 n.

The table gives the maximum number of value comparisons for each list length.

List lengthSelection sortMerge sort

1,024523,7769,217

A merge of m elements needs at most m − 1 comparisons. Add the counts for all merges.

Selection sort uses a few index variables and swaps within the input list. This merge sort uses extra lists.

A stable sort keeps equal elements in their original order. This merge sort is stable. Selection sort can reverse equal elements when it swaps.

Final review

Selection sort

RuleMeaning
SortingPut the elements in order and keep duplicate values.
Outer loopFill position i on each pass.
Start of each passSet smallest = i.
Inner loopCheck j from i + 1 to n - 1.
SelectionIf values[j] < values[smallest], set smallest = j.
SwapExchange the values at i and smallest.
Last positionAfter n - 1 passes, the last value is in place.
Comparison countn(n − 1) / 2. The input order does not change the count.
EffectThe function changes the input list in place.

For descending order, select the largest remaining value on each pass.

Merge sort and Python sorting

RuleMeaning
Base caseReturn a copy for length 0 or 1.
SplitUse mid = len(values) // 2. Sort both slices.
MergeCompare the first unused values in the two sorted lists.
AdvanceAppend the smaller value. Advance only its index.
Equal valuesTake the left value first to keep the original order.
End of the mergeAdd both remaining slices with extend.
CostAbout n log2 n work. This version uses extra lists.
values.sort()Change the input list. The method returns None.
sorted(values)Return a new sorted list. Keep the input list unchanged.

For large lists, the comparison count grows more slowly for merge sort than for selection sort.
