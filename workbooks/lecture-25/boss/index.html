How bosses work

These problems use the list algorithms from Lecture 25:

  • sum, len, and the index of the largest value
  • swaps, insert, pop, and reverse
  • sort, sorted, and list comprehensions

They use only what Lectures 4 to 25 covered:

  • input() with int() or float(), and blank input lines
  • f-strings with :.2f
  • while and for loops, range, and if statements
  • lists and the list operations above

Each problem is a script: write the statements at the top level, with no functions. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Three orders of readings

Write a program that stores integer sensor readings until the user enters -999. A sentinel ends input and is not stored. Read one integer per line.

  • Print Original: and the readings in input order as a Python list.
  • Print Descending: and a separate list in descending order.
  • Print After sorted: and the stored readings in their current order.
  • Print Ascending: and the stored readings after changing them to ascending order.
  • Keep repeated readings. For no readings, print an empty list after each label.
Example 1
Input:
7
-2
7
3
-999
Output:
Original: [7, -2, 7, 3]
Descending: [7, 7, 3, -2]
After sorted: [7, -2, 7, 3]
Ascending: [-2, 3, 7, 7]
Explanation:
The descending copy keeps the stored input order unchanged.
Example 2
Input:
-999
Output:
Original: []
Descending: []
After sorted: []
Ascending: []
Explanation:
The sentinel arrives before any reading.
Constraints
  • Each input is an integer from -999 through 999.
  • Use -999 only as the sentinel.
  • Use sorted with reverse=True for the descending display.
  • Use sort() on the stored list for the ascending display.
  • Write a script. Read input without prompts.

👾 Boss 2: Compare sensor readings with their average

Write a program that reads sensor values until a blank line. A blank line contains no characters. The average is the total divided by the number of values.

  • Read one real number per line.
  • Print Average: and the average to two decimal places.
  • Print Below: and a list of values less than the average.
  • Print Equal: and a list of values equal to the average.
  • Print Above: and a list of values greater than the average.
  • Keep input order and repeated values in each filtered list.
  • If no values were entered, print only No values.
Example 1
Input:
2
5
8
(blank line)
Output:
Average: 5.00
Below: [2.0]
Equal: [5.0]
Above: [8.0]
Explanation:
The middle reading equals the average.
Example 2
Input:
(blank line)
Output:
No values
Explanation:
The blank first line leaves no values to average.
Constraints
  • Each nonblank line is a real number from -1000 through 1000.
  • Read values with float. Use sum and len to calculate the average.
  • Build the three filtered lists with comprehensions.
  • Compare with the calculated average before rounding it for display.
  • Write a script. Read input without prompts.

🐉 Boss 3: Keep names and marks matched

Write a program that changes two related lists of student names and marks. Start with these fixed lists:

  • names = ["Lia", "Omar", "Nia", "Theo"]
  • marks = [72, 94, 94, 61]

The mark at an index belongs to the name at that index. Read a student's name, then a new index on the next line. Follow these rules in order:

  • Find the index of the highest mark with a loop. Keep the first index when marks tie.
  • Print First highest:, that student's name, and that student's mark on one line.
  • Swap that student's pair with the first pair. Print Swap names: and Swap marks: on separate lines.
  • Move the named student's pair to the requested index. The index describes the final list after the move.
  • Print Move names: and Move marks: on separate lines.
  • Reverse both lists. Print Reverse names: and Reverse marks: on separate lines.
  • After each paired change, every name must still match its mark.
Example 1
Input:
Nia
0
Output:
First highest: Omar 94
Swap names: ['Omar', 'Lia', 'Nia', 'Theo']
Swap marks: [94, 72, 94, 61]
Move names: ['Nia', 'Omar', 'Lia', 'Theo']
Move marks: [94, 94, 72, 61]
Reverse names: ['Theo', 'Lia', 'Omar', 'Nia']
Reverse marks: [61, 72, 94, 94]
Explanation:
Omar wins the tie. Nia moves to the first index before reversal.
Example 2
Input:
Theo
3
Output:
First highest: Omar 94
Swap names: ['Omar', 'Lia', 'Nia', 'Theo']
Swap marks: [94, 72, 94, 61]
Move names: ['Omar', 'Lia', 'Nia', 'Theo']
Move marks: [94, 72, 94, 61]
Reverse names: ['Theo', 'Nia', 'Lia', 'Omar']
Reverse marks: [61, 94, 72, 94]
Explanation:
The last index is a valid destination. Theo already occupies that index.
Constraints
  • The name is exactly one of Lia, Omar, Nia, or Theo.
  • The new index is an integer from 0 through 3.
  • Use a loop for the highest-mark index. Do not use max or index for that step.
  • Use the swap idiom on each list.
  • Use pop and insert on both lists for the move.
  • Use reverse() on both lists after the move.
  • Write a script. Read input without prompts.

💀 Boss 4: Fit a line to sensor points

Write a program that fits a straight line to sensor points. A point has an x value and a y value. Store x values and y values in two related lists.

  • Read each x value on its own line. A blank x line ends input.
  • After each nonblank x line, read its y value on the next line.
  • A blank line contains no characters. It cannot replace a y value.
  • Print the fitted line in the form y = mx + b.
  • Replace m and b with the calculated coefficients, each to two decimal places.
  • For a negative intercept, print a minus sign and its positive magnitude after x.
  • Print Need at least two points when fewer than two points were entered.
  • Print Cannot fit a line when all x values are equal.

The slope m measures the change in y for one unit of x. The intercept b is the fitted y value when x is zero. Use these values:

  • n is the number of points.
  • sx is the sum of all x values.
  • sy is the sum of all y values.
  • sxx is the sum of each x value squared.
  • sxy is the sum of each x value multiplied by its matching y value.
ValueFormula
dsxx − sx2 / n
m(sxy − sx sy / n) / d
bsy / n − m sx / n

If d = 0, the line cannot be fitted. Round the calculated coefficients to two decimal places before choosing the intercept sign. Treat a rounded zero as positive zero.

y = 1.75x - 0.83
Explanation:
The points do not lie on one line. The formula fits a line to all three.

Explanation:

Example 3

2

(blank line)

Explanation:

Constraints
  • Each nonblank number is an integer from -100 through 100. Read it with float.
  • Read at most 100 points. Every nonblank x line has a valid y line.
  • Use two related lists. Keep each point at the same index in both lists.
  • Compute all four sums with sum and comprehensions over indexes.
  • Use round(value, 2) for coefficient rounding and .2f for display.
  • Write a script. Read input without prompts.
