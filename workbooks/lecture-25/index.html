5. Index changes after insertion and removal

An insertion shifts later elements to the right. A removal shifts later elements to the left.

After statementvalues
Create[10, 30, 40]
insert(1, 20)[10, 20, 30, 40]
pop(2)[10, 20, 40]

insert(1, 20) puts 20 before the element at index 1. Then 30 is at index 2, so pop(2) removes 30.

6. Reverse order and slices

reverse() changes the existing list. A slice with step -1 makes a new list in reverse order.

reverse() returns None.

The slice form is values[start:stop:step]. Here, both endpoints are omitted. Reverse order does not necessarily mean descending order.

10. Building a list with a comprehension

A list comprehension creates a new list. It evaluates one expression for each element of a sequence.

For each n, evaluate n * n and add the result to the new list.

lengths contains the number of characters in each name. The input order determines the result order.

namelen(name)Result so far
"Ada"3[3]
"Alan"4[3, 4]
"Grace"5[3, 4, 5]

Each iteration adds one result element. The comprehension does not change names.

Final review

List algorithms and order

OperationRule
sum(a), len(a)Both return 0 for []. Check the length before division.
max(a), min(a)Use a nonempty list.
Largest positionStart with best = 0. Compare a[i] with a[best]. Use > to keep the first maximum.
a[i], a[j] = a[j], a[i]Both right-hand values are evaluated before assignment.
a.insert(i, x), a.pop(i)Later elements shift. pop returns the removed element.
a.reverse(), a[::-1]The method changes a. The slice returns a new reversed list.
a.sort(), sorted(a)sort changes a and returns None. sorted returns a new list.
reverse=TrueSelect descending order with sort or sorted.
reversed(a)It keeps a unchanged. Use list(reversed(a)) to get a list.

Copies, functions, and comprehensions

FormMeaning
b = aBoth names refer to one list.
b = a[:]This assignment makes a separate copy of a flat list.
A list parameterElement changes also affect the caller's list.
A new result listCreate a separate list. Return that list. Keep the input unchanged.
[2*x for x in a]Double each element. Collect the results in a new list.
[x for x in a if x>=0]Keep each element that meets the condition. Preserve the input order.
An empty input sequenceThe comprehension returns [].
Loop or comprehensionUse a loop for several actions. Keep comprehensions simple.
