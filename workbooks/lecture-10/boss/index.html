How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 10 covered: input() with int() and float(), arithmetic including % and **, string indexes, f-strings, comparisons, and decisions with if, elif, and else, including one decision nested inside another. There is no and or or yet. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its value with input(). Keep that line exactly as it is: Check runs your program several times, typing a different answer at the prompt each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Name That Shape

The stop signs along Prince Philip Drive have eight sides. You are given a number of sides, sides. Print the name of the shape for 3 to 10 sides: triangle, quadrilateral, pentagon, hexagon, heptagon, octagon, nonagon, decagon. For any other count, say the program does not know it.

Read sides with input() and print one sentence.

Example 1
Input: sides = 8
Output: A shape with 8 sides is an octagon.
Example 2
Input: sides = 2
Output: A shape with 2 sides is not one this program knows.
Constraints
  • 0 <= sides <= 100
  • Store the name with its article (a triangle, an octagon) so one print works for every branch.

The program reads the count after the prompt Sides: .

Sides: 8
A shape with 8 sides is an octagon.
TypedOutput
8A shape with 8 sides is an octagon.
3A shape with 3 sides is a triangle.
10A shape with 10 sides is a decagon.
2A shape with 2 sides is not one this program knows.
11A shape with 11 sides is not one this program knows.
6A shape with 6 sides is a hexagon.
Rules the checker enforces
  • One if/elif/else chain, ending with else.
  • No and, or, or not.
  • One print(), after the chain.
  • End the sentence with a full stop.

Keep the line sides = int(input('Sides: ')) unchanged. The checker will type the other counts.

💀 Boss 4: Note to Frequency

A note name is a letter and an octave number, like A4. The table gives the seven notes of the fourth octave, starting at middle C. A note one octave higher has twice the frequency and a note one octave lower has half of it, so A5 is 880.00 Hz and A3 is 220.00 Hz. You are given a note name, note, from C0 to B8. Print its frequency with two decimal places.

NoteFrequency (Hz)
C4261.63
D4293.66
E4329.63
F4349.23
G4392.00
A4440.00
B4493.88

Read note with input() and print one line. A chain with one branch per octave would need 63 cases. Use one chain for the letter only and arithmetic for the octave.

Example 1
Input: note = A4
Output: A4 has a frequency of 440.00 Hz.
Example 2
Input: note = C5
Output: C5 has a frequency of 523.26 Hz.
Explanation: One octave above C4, so 2 * 261.63.
Example 3
Input: note = C0
Output: C0 has a frequency of 16.35 Hz.
Explanation: Four octaves below C4, so 261.63 halved four times.
Constraints
  • note is two characters: a capital letter from A to G, then a digit from 0 to 8.
  • The note is always valid.

The program reads the note after the prompt Note: .

Note: A4
A4 has a frequency of 440.00 Hz.
TypedOutput
A4A4 has a frequency of 440.00 Hz.
C4C4 has a frequency of 261.63 Hz.
C5C5 has a frequency of 523.26 Hz.
A3A3 has a frequency of 220.00 Hz.
C0C0 has a frequency of 16.35 Hz.
B8B8 has a frequency of 7902.08 Hz.
G6G6 has a frequency of 1568.00 Hz.
Rules the checker enforces
  • Pick the letter and the digit out of note with indexes.
  • One chain of seven branches for the letter: an if, five elif, and an else.
  • Use ** to move to the right octave.
  • No and, or, or not.
  • Show the frequency with .2f and print one line.

Keep the line note = input('Note: ') unchanged. The checker will type the other notes.
