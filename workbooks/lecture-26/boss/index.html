Lists with functions and tables

Pranjal Patra

How bosses work

These problems use lists with functions and tables from Lecture 26:

  • functions that take a list and either change it or return a new list
  • a None default for a list parameter
  • tables with independent rows, row totals, and column totals

They use only what Lectures 4 to 26 covered:

  • input() with int(), and blank input lines
  • f-strings with :.2f, and random.seed with random.randint
  • while and for loops, range, and if statements
  • lists, slices, sorted, pop, and list comprehensions

Each problem names the functions to write. Write the rest of the program at the top level, after the functions. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show. Check also calls your functions directly with other lists.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Format a shop list

Write a program that reads shop words until a blank line. Read one word per line. A blank line contains no characters and ends input. Write word_list_text(words) to return one string.

  • Keep the word order and the input list unchanged.
  • Separate earlier words with a comma and one space. Put one space before and after "and".
  • For two words, use only "and" between them. For one word, return that word.
  • For no words, return an empty string.
  • Print Words:, one space, and the returned string.
Example 1
Input:
tea
rice
salt
(blank line)
Output:
Words: tea, rice and salt
Explanation:
Only the final pair uses and.
Example 2
Input:
(blank line)
Output:
Words:
Explanation:
The function returns an empty string.
Example 3
Input:
bread
(blank line)
Output:
Words: bread
Explanation:
One word needs no separator.
Example 4
Input:
tea
rice
(blank line)
Output:
Words: tea and rice
Explanation:
Two words need no comma.
Constraints
  • Each word contains lowercase English letters. Read at most 20 words.
  • Build the string in a loop. Use a slice for all but the last word.
  • Read input without prompts.

To enter the blank line, press Enter without typing anything. Check types each of these sequences. The examples are the first four rows.

  • Define word_list_text(words) with one parameter. It returns the string and keeps its input unchanged.
  • In word_list_text, loop over a slice that holds all but the last word.
  • Do not use join.

👾 Boss 2: Trim extreme readings

Write a program that reads integer sensor readings until a blank line. Read one value per line. A blank line ends input and is not a value. An extreme reading is one of the smallest or largest values.

  • Write trimmed_copy(values, n) to return a sorted copy with n values removed from each end.
  • Keep the input list unchanged. Count repeated values separately.
  • The program uses n = 2.
  • If fewer than four values were entered, print only Need at least four values.
  • Otherwise, print Original: and the input list. Then print Trimmed: and the result.
Example 1
Input:

2
8
5
11
17
(blank line)
Output:
Original: [14, 2, 8, 5, 11, 17]
Trimmed: [8, 11]
Explanation:
Two values are removed from each end of the sorted copy.
Example 2
Input:
7
1
9
4
(blank line)
Output:
Original: [7, 1, 9, 4]
Trimmed: []
Explanation:
Exactly four values leave no middle readings.
Example 3
Input:
(blank line)
Output:
Need at least four values
Explanation:
No readings were entered.
Constraints
  • Each reading is an integer from -1000 through 1000.
  • For function calls, n is a nonnegative integer and 2 * n <= len(values).
  • Use sorted and the slice [n:len(values) - n].
  • Test the function separately with n = 0. Read input without prompts.

🐉 Boss 3: Report a scores table

Write a program that reads a scores table. Read the number of students, then the number of tests, on separate lines. Then read one integer score per line, in row order. Each row belongs to one student. Each column belongs to one test.

  • Write table_with_row(row, table=None). Return a new table containing copies of the earlier rows and a copy of row.
  • When the table argument is omitted or None, start a new table. Keep both inputs unchanged.
  • Use the function to build the scores table. Every row must be independent.
  • Print Scores: and the table. Print each row total with row numbers starting at 1.
  • Print each column average to two decimal places. An average is the column total divided by the number of students.
  • Then set cell [0][0] to 100. Print After change: and the table.
  • Make two separate calls without a table, with rows [7] and [9].
  • Set the first returned table's cell [0][0] to 0. Print both tables after Default tables:.
Example 1
Input:
2
3
10
20
30
40
50
60
Output:
Scores: [[10, 20, 30], [40, 50, 60]]
Row 1 total: 60
Row 2 total: 150
Column 1 average: 25.00
Column 2 average: 35.00
Column 3 average: 45.00
After change: [[100, 20, 30], [40, 50, 60]]
Default tables: [[0]] [[9]]
Explanation:
The second row keeps all its scores after the first row changes.
Example 2
Input:

1
8
Output:
Scores: [[8]]
Row 1 total: 8
Column 1 average: 8.00
After change: [[100]]
Default tables: [[0]] [[9]]
Explanation:
One score is both the row total and the column average.
Constraints
  • Each dimension is an integer from 1 through 5.
  • Each score is an integer from 0 through 100.
  • Use a None default and independent row copies.
  • Use loops to read scores and calculate column totals. Read input without prompts.

💀 Boss 4: Deal reproducible card hands

Write a program that reads a player count and a card count per player on separate lines. A deck contains 52 cards. Each card has a rank and a suit. Use two-character card codes.

  • Ranks are 2 through 9, then T, J, Q, K, and A.
  • T means ten. The other letters mean jack, queen, king, and ace.
  • Suits are C for clubs, D for diamonds, H for hearts, and S for spades.
  • For example, QC is the queen of clubs.

Write these functions:

  • create_deck() returns a new list. Use suit order CDHS and rank order 23456789TJQKA.
  • shuffle_deck(deck) changes the deck in place and returns None.
  • deal(deck, players, cards) removes cards from the deck and returns a table of hands with independent rows.
  • Deal in rounds. Give each player one card before starting the next round.
  • Use pop(0) to take the next card.
  • If the deal needs more than 52 cards, print only Not enough cards.
  • Otherwise, print one labeled hand per line, then Remaining: and the number of cards left.

Use the shuffle rules in Constraints so everyone gets the same model output.

Example 1
Input:
3
2
Output:
Hand 1: ['KH', 'QS']
Hand 2: ['JS', '5D']
Hand 3: ['4S', 'AD']
Remaining: 46
Explanation:
Each round removes one card for each of the three players.
Example 2
Input:
2
0
Output:
Hand 1: []
Hand 2: []
Remaining: 52
Explanation:
Zero cards leaves the deck full and both hands empty.
Example 3
Input:
5
11
Output:
Not enough cards
Explanation:
Five hands of eleven cards need 55 cards.
Constraints
  • The player count is an integer from 1 through 52. The card count per player is an integer from 0 through 52.
  • Call random.seed(26) once at the start of the program.
  • For the shuffle, visit indexes from len(deck) - 1 down to 1.
  • At each index i, choose j = random.randint(0, i) and swap those cards.
  • Build hands with a comprehension of fresh empty lists. Read input without prompts.
