Lists with functions

1. Shared list parameters and local assignment

clear_negatives replaces negative elements with 0. It changes the input list in place. Python copies the reference into the parameter. It does not copy the list. Without a return value, this function returns None.

During the call, both names refer to the same list.

reset_local assigns an empty list to its parameter. It leaves the caller's list unchanged. values = [] changes the local reference. values[0] = 0 changes a shared element.

After the assignment, values refers to a separate empty list. marks still refers to the original list.

2. New lists and function styles

nonnegative_copy replaces negative values with 0 in a new list. The input stays unchanged. State the function's effect in its description. An in-place function changes its input. A copy function creates a separate list.

marks and clean refer to two separate lists.

fix_marks changes its input and returns the same list. Use a verb name such as clear_negatives to change a list. Return None. Say in the description that the function changes the list in place.

Use a noun name such as nonnegative_copy to make a new list. Return the new list. Keep the input unchanged. Do not change and return the same list. The caller of fix_marks probably expected marks to stay [6, -2, 4].

Tables

5. A table is a list of rows

A table stores values in rows and columns. Each element of the outer list is a row list. This rectangular table has two rows and three columns.

The outer list has two elements, at indexes 0 and 1. Each element refers to one row list.

6. Row first, then column

table[row][col] selects a row, then an element of that row. Both indexes start at 0. len(table) counts rows. len(table[row]) counts elements in that row. An empty table has no row 0.

For this table, valid row indexes are 0 and 1. Valid column indexes are 0, 1, and 2.

col 0col 1col 2
row 0246
row 1135 = table[1][2]

Read table[r][c] as "row first, then column". grid[0][2] selects row 0, column 2. grid[2][0] selects row 2, column 0. In a square table, swapping two valid indexes causes no index error. The program can give a wrong value without a warning.

8. Shared rows and independent rows

Repeating the outer list copies row references. This construction does not create independent rows. Only one row list exists. Both outer elements refer to it. Changing the cell through either reference changes that same row.

Create each row inside the loop. Each evaluation of [0] * 3 makes a separate row list. A comprehension can create the same independent rows. For numeric cells, repeating 0 within one row is safe. Repeating the row reference causes the problem.

Table operations

9. Copy each numeric row

For a numeric table, copy each row to make independent cells. An outer slice alone keeps the row references. table[0] and outer[0] refer to one row.

Each row[:] creates a new row list. These cells contain numbers. More deeply nested data can require further copying.

11. A column total

column_total adds the value at column col from every row. It leaves the table unchanged. Column 1 means the second column. total starts at 0 before the loop. It continues across rows.

Every row must contain column col. Otherwise, indexing causes an IndexError. For an empty table, the function returns 0.

A row total needs only sum(table[r]), but a column total needs a loop over every row.
