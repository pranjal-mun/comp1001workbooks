1. Boolean Values and Operators

Boolean variables

The type bool has exactly two values: True and False. These words begin with capital letters. They are values, not strings. A comparison produces a Boolean value, and a variable can store it.

Choose a name that reads like a true-or-false statement. Names such as is_valid, has_paid, can_edit, and was_found explain what True means. A vague name such as flag does not.

Use a Boolean variable directly as a condition. Do not compare it with True or False.

Write if not is_valid: when a block should run for the false case. A positive name is usually easiest to read. A name such as is_not_empty can lead to the confusing condition not is_not_empty.

The and operator

The expression A and B is True only when both parts are True. Use and when every requirement must pass.

If either requirement fails, the whole expression is False.

The or operator

The expression A or B is True when at least one part is True. Python uses inclusive or: the result is also True when both parts are True.

Use or when any one acceptable case is enough. Do not use it when the rule requires exactly one case.

Precedence

Python evaluates comparisons before Boolean operators. Among the Boolean operators, the precedence order is not, then and, then or. Therefore, a or b and c means a or (b and c).

Parentheses make intended grouping clear. Add them when a reader may need to stop and work out the precedence.

2. Readable and Safe Conditions

Short-circuit evaluation

Python evaluates a Boolean expression from left to right and stops when the answer is already known. This behaviour is short-circuit evaluation.

  • For and, a false left side makes the whole expression false, so Python skips the right side.
  • For or, a true left side makes the whole expression true, so Python skips the right side.

This is useful for safety as well as speed. Put a guard first and the operation it protects second.

The left side is false, so Python never evaluates total / count. No division by zero occurs. Reversing the two tests would be unsafe.

De Morgan's laws

Compound negations can be difficult to read. De Morgan's laws give two equivalent forms:

  • not (A and B) is the same as (not A) or (not B).
  • not (A or B) is the same as (not A) and (not B).

Moving not inward reverses each part and swaps and with or. Forgetting to swap the operator changes the meaning.

The two expressions have the same value for every possible input combination.

Chained comparisons

Python lets one value appear in a chain of comparisons. The expression 0 <= score <= 100 means the same as 0 <= score and score <= 100. The chained form keeps the tested value in the middle, as it appears in mathematics.

The boundaries are included because the chain uses <=. To exclude a boundary, use < at that end.

String methods that return Booleans

Several string methods answer a yes-or-no question and return a Boolean value.

MethodQuestion it answers

text.isalpha()Is the nonempty text made only of letters?
text.isspace()Is the nonempty text made only of whitespace?

The first result is false because code contains digits as well as letters. The empty string fails isdigit() and isalpha(). Also, '-5'.isdigit() is false because the minus sign is not a digit, and '3.5'.isdigit() is false because the decimal point is not a digit.

Validate before converting

Input validation checks whether user input is usable before a program uses it. Place validation close to the input() call. Then later code can rely on the value having passed the checks.

When text should contain a nonnegative whole number, test isdigit() before calling int(). Converting first would defeat the check because bad text would already cause a ValueError.

Sample run with invalid text:

Enter your age: twenty
Please enter a whole number.

Sample run with valid text:

Enter your age: 24
Age recorded: 24

The order matters. Python reaches int(raw) only when the text contains digits.

Putting It All Together

A registration program asks for a course code and a seat count. It accepts a request only when the code begins with COMP, the seat text contains digits, and the converted count is from 1 through 40.

Build the program in stages. First, clean the two inputs. At this point both values are still strings.

Next, name the tests that are safe before conversion.

is_comp_course = course.startswith('COMP')
has_whole_seats = raw_seats.isdigit()

Only the branch where has_whole_seats is true may convert the text. The range test therefore belongs inside that branch.
