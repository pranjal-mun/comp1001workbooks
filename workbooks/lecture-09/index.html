1. Comparison Expressions

A comparison asks how two values are related. It is an expression, so it produces a value. The value is either True or False.

True and False belong to the type bool, short for Boolean. Python capitalizes both words.

You can use a comparison directly as an if condition, or store its result in a variable first.

5. String Equality

Two strings are equal only when they contain the same characters in the same order with the same capitalization.

Spaces and punctuation are characters too. Therefore, 'yes', 'Yes', and 'yes ' are three different strings.

6. Lexicographic String Order

Python compares strings character by character. This is called lexicographic order. It is similar to dictionary order, but character codes create some important differences:

  • uppercase letters come before lowercase letters;
  • digits come before letters; and
  • if one string is the beginning of another, the shorter string comes first.

Do not assume string ordering always matches the order a person would expect in a name list. Capitalization can change the result.

8. Floating-Point Comparisons

Floating-point calculations can contain tiny rounding differences. Exact equality may therefore reject values that are close enough for the problem.

For computed floats, compare the size of the difference with a small tolerance. The function abs() returns a nonnegative distance from zero.

The appropriate tolerance depends on the problem. The important pattern is abs(x - y) < tolerance, not one fixed tolerance for every program.

9. Mixed-Type Comparisons

Numeric int and float values can be compared by value. Text and numbers do not represent the same kind of value.

Equality between a string and a number produces False. An ordering comparison between them has no sensible meaning and raises a TypeError.

Python reports an error similar to:

TypeError: '<' not supported between instances of 'str' and 'int'

This is why numeric text returned by input() must be converted before it is compared with a number.

Putting It All Together

A calibration report

This example combines a stored Boolean value, case-insensitive string comparison, floating-point tolerance, a boundary, and two independent decisions. The program checks a sensor label and then checks a measurement.

The rules are:

  • the expected label is sensor-a, but capitalization does not matter;
  • a measurement is accepted when it is less than 1.0 degree away from the target;
  • a difference of exactly 1.0 is outside the tolerance.

First, write each condition as an expression that produces a Boolean value.

label_matches = entered_label.lower() == expected_label.lower()
within_tolerance = abs(measured - target) < tolerance

The program stores each result before the corresponding decision. Run it and type your own values when prompted.

Sample run within the tolerance:

Sensor label: SENSOR-A
Label accepted
Measured value: 20.4
Target value: 20
Measurement accepted

Sample run at the tolerance boundary:

Sensor label: sensor-a
Label accepted
Measured value: 21
Target value: 20
Measurement outside tolerance

The second result uses the outside path because abs(21 - 20) is exactly 1.0. The condition uses <, not <=.
