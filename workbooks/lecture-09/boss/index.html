How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 9 covered: input() with int() and float(), arithmetic, f-strings, the six relational operators, abs(), one if with an else, and separate if statements one after another. There is no elif and no and or or yet. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with input(). Keep those lines exactly as they are: Check runs your program several times, typing different answers at the prompts each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 🐉 and are worth 10, 15, and 20 XP.

👹 Boss 1: In Tune

Before a concert in the D.F. Cook Recital Hall, the oboe plays the note A4 at 440 Hz and every other player tunes to it. You are given a reading from a tuner, reading, in hertz. A string counts as in tune when it is within 1 Hz of A4, on either side. Print whether the reading is in tune, and if not, how far from A4 it is.

Read reading with input() as a float and print one line.

Example 1
Input: reading = 440.5
Output: 440.5 Hz is in tune with A4.
Example 2
Input: reading = 445
Output: 445.0 Hz is 5.0 Hz away from A4.
Explanation: The distance is shown with one decimal place.
Example 3
Input: reading = 439
Output: 439.0 Hz is in tune with A4.
Explanation: 439 is exactly 1 Hz below A4, which still counts as in tune.
Constraints
  • 0 < reading <= 5000

The program reads the value after the prompt Frequency (Hz): .

440.5 Hz is in tune with A4.

Rules the checker enforces
  • Exactly one if with an else. No elif, and, or or.
  • Use abs() so one comparison covers readings above and below 440.
  • A distance of exactly 1 Hz is in tune.
  • Print one line.

Keep the line reading = float(input('Frequency (Hz): ')) unchanged. The checker will type the other readings.

👾 Boss 2: Equilateral or Not

A triangle is equilateral when all three of its sides have the same length. You are given the three side lengths, a, b, and c. Print whether the triangle is equilateral.

Read the three sides with input() as float values and print one line. Lecture 9 has no and yet, so start with kind = 'equilateral' and let separate if statements change it.

Example 1
Input: a = 3, b = 3, c = 3
Output: A triangle with sides 3.0, 3.0 and 3.0 is equilateral.
Example 2
Input: a = 5, b = 5, c = 5.5
Output: A triangle with sides 5.0, 5.0 and 5.5 is not equilateral.
Explanation: Two equal sides are not enough.
Constraints
  • 0 < a, b, c <= 1000
  • The three lengths always form a triangle.

🐉 Boss 3: Phone Bill

A phone plan gives 50 minutes of calls and 50 text messages for $15.00 a month. Every extra minute costs $0.25 and every extra text costs $0.15. Each bill also carries a 911 fee of $0.44, and the whole bill, fee included, is taxed at 15 percent, the HST rate in Newfoundland and Labrador. You are given the minutes used, minutes, and the texts sent, texts. Print the bill, one charge per line, with two decimal places.

Read the two counts with input() as int values. Print the base plan, then the extra minutes and the extra texts only when there is a charge for them, then the 911 fee, the tax, and the total.

Example 1
Input: minutes = 60, texts = 70
Output:
Base plan: $15.00
Extra minutes: $2.50
Extra texts: $3.00
911 fee: $0.44
Tax: $3.14
Total: $24.08
Explanation: 10 extra minutes at $0.25 and 20 extra texts at $0.15. The tax is 15 percent of 20.94.
Example 2
Input: minutes = 50, texts = 50
Output:
Base plan: $15.00
911 fee: $0.44
Tax: $2.32
Total: $17.76
Explanation: Exactly 50 of each is still inside the plan, so no extra lines are printed.
Constraints
  • 0 <= minutes <= 10000
  • 0 <= texts <= 10000
