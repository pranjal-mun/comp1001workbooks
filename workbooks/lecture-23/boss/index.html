How bosses work

These problems compare loops and recursion from Lecture 23:

  • a loop that updates a few values in one function frame
  • a recursive function that solves a smaller version of the same task
  • the cost of unfinished calls and of repeated smaller problems

They use only what Lectures 4 to 23 covered:

  • input() with int(), and blank input lines
  • arithmetic, including // and %
  • strings, len, str, indexing, and slices
  • while loops and if statements
  • functions, recursion, main(), and the __name__ guard

Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Check also calls your functions directly with more values and compares what they return. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the examples show.

Each problem also asks you to compare or trace your functions. Those parts are under the code box. Check grades only the program.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 👾 and are worth 10 and 15 XP.

👹 Boss 1: Binary, two ways

Write binary_rec(n) and binary_loop(n). Each function converts a nonnegative integer to a binary string. Binary uses the digits 0 and 1. Its place values from right to left are 1, 2, 4, 8, and successive powers of 2. You have already written a loop for base conversion. Write both versions here, then compare them.

Follow these rules:

  • Return a string with no leading zeros for a positive input.
  • Return "0" for zero.
  • The conversion functions return strings and do not print.
  • Read one integer in main().
  • For a negative integer, print Error: enter a nonnegative integer.
  • Otherwise, print both results with the labels shown in the examples.

Write these functions:

  1. binary_rec(n) uses recursion to return the binary string.
  2. binary_loop(n) uses a loop to return the binary string.
  3. main() reads the input and prints the required output.
Example 1
Input:
13
Output:
Recursive: 1101
Loop: 1101
Explanation:
The digits represent 8 + 4 + 1, which is 13.
Example 2
Input:
0
Output:
Recursive: 0
Loop: 0
Explanation:
Both functions return the one-character string "0".
Example 3
Input:
-1
Output:
Error: enter a nonnegative integer
Explanation:
The program rejects the negative input before conversion.
Constraints
  • The entered integer is from −1 through 65,535.
  • Each conversion function accepts only nonnegative integers.
  • Use recursion with no loop in binary_rec.
  • Use a loop with no recursion in binary_loop.
  • Do not use bin(), formatting codes for binary, lists, or dictionaries.
  • Use the three required functions and the standard guard.

Rules the checker enforces
  • Define binary_rec(n) and binary_loop(n) with one parameter each, and main with empty parentheses.
  • Use recursion in binary_rec: call binary_rec inside its own body. Use no loop in it, and do not call binary_loop from it.
  • Use a for or while loop in binary_loop. Do not call binary_loop or binary_rec from it.
  • Do not use bin(), format(), or a binary format code such as :b.
  • Do not use lists, dictionaries, global variables, or imports.
  • The conversion functions return strings and do not print. Check also calls both of them with every value up to 300, and with values such as 512, 1023, and 40000.
  • End the file with the standard guard.
Compare the two versions

Which version do you prefer for this task? Give one reason about clarity and one about unfinished calls.

👾 Boss 2: The fewest edits

Write edit_distance(s, t). It returns the smallest number of single-character edits needed to change string s into string t. An edit is one of these operations:

  • Insert one character.
  • Delete one character.
  • Substitute one character for another.

Each edit costs 1. Matching characters need no edit. For example, changing "at" to "cat" needs one insertion.

Follow these rules:

  • If one string is empty, count the characters in the other string.
  • For two nonempty strings, make three recursive calls.
  • One call removes the last character from s only.
  • One call removes the last character from t only.
  • One call removes the last character from both strings.
  • Include each operation's cost when comparing the three answers.
  • You may use min(a, b, c), which returns the smallest of its three arguments.
  • Do not save earlier answers for reuse across calls.

Write these functions:

  1. edit_distance(s, t) returns the distance using recursion.
  2. main() reads two lines and prints Distance: followed by the distance.
Example 1
Input:
at
cat
Output:
Distance: 1
Explanation:
Insert c at the start of at to get cat.
Example 2
Input:
(blank line)
go
Output:
Distance: 2
Explanation:
Insert g and o into the empty string.
Example 3
Input:
ab
ac
Output:
Distance: 1
Explanation:
Substitute c for b. The first character already matches.
Constraints
  • Each input has 0 through 4 lowercase English letters.
  • A blank line is an empty string.
  • Use three recursive calls in every call with two nonempty strings.
  • Use no loops, lists, or dictionaries.
  • Use the two required functions and the standard guard.

In Example 2 the first line is blank: press Enter without typing anything. The program reads both lines with no prompt.

Rules the checker enforces
  • Define edit_distance(s, t) with two parameters and main with empty parentheses.
  • Make three recursive calls: call edit_distance three times inside its own body.
  • Stop only when a string is empty, and do not save earlier answers. Check counts the calls. For example, edit_distance("ab", "ac") must make 19 calls in all.
  • Use no loops. Do not use lists, dictionaries, global variables, or imports.
  • edit_distance returns its answer and does not print. Check also calls it with pairs such as ("dog", "god"), ("star", "rats"), and ("a", "aaaa").
  • End the file with the standard guard.
Trace and explain

Trace enough of edit_distance("ab", "ac") to find one repeated pair of string arguments. Write two call paths that reach that pair. State the distance returned for the pair.
