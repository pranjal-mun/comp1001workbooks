The recursive idea

1. The recursive idea

You already break problems into smaller pieces. Recursion is when a piece has the same shape as the whole problem. To find the total up to 5, use the total up to 4 and add 5.

The first three rows of a triangle contain 6 squares. The new row adds 4 squares. triangle(4) is triangle(3) plus 4, so 10 = 6 + 4. The triangle number for n is 1 + 2 + ⋯ + n.

A base case is an input we can answer directly. With zero rows, the triangle has zero squares. triangle(0) returns 0. In the recursive case, the function calls itself with a smaller input. It uses that answer to build this answer. For n > 0, return n + triangle(n - 1).

The recursive case must move toward a base case. The base case returns without making another recursive call.

The six stages still apply:

UnderstandState the allowed inputs and the required answer.
DecomposeSplit off one part. Leave a smaller problem.
Find patternsCheck that the smaller problem has the same task.
DesignChoose the base case. Decide how to use the smaller answer. Check small examples.
ImplementWrite the base case and the recursive case in Python.
ReflectExplain why the input gets smaller. Check that the base case is reachable.

For a triangle, remove the last row. The remaining rows form a smaller triangle.

Triangle numbers

2. Triangle numbers

triangle(n) returns the sum of the integers from 1 to n. triangle(4) returns 1 + 2 + 3 + 4 = 10. Assume n is a nonnegative integer.

n == 0 selects the base case. triangle(n - 1) is the recursive call. Adding n builds the answer for this input.

Base? means n == 0. Record the calls from top to bottom. Fill the returned values from bottom to top. The final answer is 6.

Suppose triangle(3) gives the correct answer, 6. Then triangle(4) adds 4 to get 10. To write the larger case, work out how to use that smaller answer.

The base case gives a correct starting answer. Each step builds a correct answer from a smaller one. All allowed inputs reach that starting case.

Factorial and design

4. Factorial

The factorial of 4 is written 4!.

4! = 4 × 3 × 2 × 1 = 24

The last three factors form the factorial of 3, so 4! = 4 × 3!. The base case is 0! = 1. An empty product has value 1.

Assume n is a nonnegative integer. The base case returns 1. The recursive case multiplies by n. The problem decides the base answer. A sum starts at 0. This product starts at 1.

The calls go down to the base case. The products come back as the calls finish:

  1. The calls use n values 4, 3, 2, 1, and 0, in that order.
  2. The base case returns 1.
  3. The call with n = 1 returns 1 × 1 = 1.
  4. The call with n = 2 returns 2 × 1 = 2.
  5. The call with n = 3 returns 3 × 2 = 6.
  6. The call with n = 4 returns 4 × 6 = 24.

Each larger call multiplies by its own n.

5. One stack frame per call

Each call gets its own n in its own stack frame. The latest unfinished call is on top. The calls below it wait for an answer. Python also remembers where each call must continue. While factorial(0) runs, the four factorial frames are:

factorial(0) and factorial(1) each return 1. Next, factorial(2) returns 2 × 1 = 2. Then factorial(3) returns 3 × 2 = 6 to its caller. The returning call's frame finishes. The frame below it becomes active. After factorial(3) returns, all four factorial frames have finished.

Call numberCallBase?Returned value
1factorial(3)False3 × 2 = 6
2factorial(2)False2 × 1 = 2
3factorial(1)False1 × 1 = 1
4factorial(0)True1

Base? means n == 0. Start with the base answer, 1. Work upward through the multiplications. The final answer is 6.

Reaching the base case

6. Reaching the base case

This function has a recursive case but no base case.

Starting with broken(2), the inputs are 2, 1, 0, and then −1. The input gets smaller, but no case returns directly. The calls continue past zero. After too many nested calls, Python raises RecursionError.

Valid code can also reach Python's recursion limit on a very large input. Use small inputs while learning the pattern.

Other smaller inputs

7. Removing a digit

For a nonnegative integer, // 10 removes the last digit. The expression % 10 gives that digit. 407 // 10 is 40, and 407 % 10 is 7. digit_sum(407) is digit_sum(40) plus 7. A single digit is a base case. Its digit sum is the digit itself. This includes 0.

8. Shortening a string

A string can also get shorter. reverse(text) returns the characters of text in the opposite order.

text[1:] is the text after its first character. Reverse "AT" to get "TA". Then add "C" at the end. Empty text and a single character are base cases.
