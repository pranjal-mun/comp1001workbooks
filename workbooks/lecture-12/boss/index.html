How bosses work

A boss problem is bigger than the practice questions in the workbook, but it only uses what Lectures 4 to 12 covered: input() with int() and float(), arithmetic including %, string indexes and len(), f-strings, if statements, and the while loop with its initialization, test, and update. These problems combine the loop patterns from this lecture with ideas from earlier lectures. Plan the initialization, test, and update before writing each program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here reads its values with input(). Keep those lines exactly as they are: Check runs your program several times, typing different answers at the prompts each time, and every run must print exactly what the table shows. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Campus Shop Clearance Table

The Memorial University campus shop has reduced some course supplies by 25 percent. Read the first original price and the number of rows to display. The first row uses the entered price. Each later row increases the original price by $5.00. Print the heading shown below, followed by the original price, discount, and sale price for each row. Show every amount with two digits after the decimal point. If the number of rows is 0, print the heading and no price rows.

First price: $20
Rows: 3
Original  Discount  Sale
$20.00  $5.00  $15.00
$25.00  $6.25  $18.75
$30.00  $7.50  $22.50

The starter prints the heading and sets count to 0. Loop while count < rows. On each pass, discount is price * DISCOUNT_RATE (5.0 for the first row above) and the sale price is price - discount. Print the three amounts in one f-string with :.2f and two spaces between them, then add 5 to price and 1 to count. When rows is 0, the first test is false and only the heading is printed.

TypedOutput after the heading
20, 3$20.00 $5.00 $15.00
$25.00 $6.25 $18.75
$30.00 $7.50 $22.50
12.5, 0nothing
9.99, 2$9.99 $2.50 $7.49
$14.99 $3.75 $11.24

Rules the checker enforces
  • Repeat the work with a while loop. No for.
  • Work out the discount with price * DISCOUNT_RATE; do not write 0.25 again.
  • Show every amount with :.2f in the f-string.
  • One print() inside the loop for the rows, and the heading print() outside it.
  • Add 1 to count on every pass so the loop stops after rows passes.

Keep the lines price = float(input('First price: $')) and rows = int(input('Rows: ')) unchanged. The checker will type the other prices and row counts.

👾 Boss 2: Shared Tutorial Teams

Pranjal wants to divide two tutorial groups into teams. Every team must have the same number of students, and nobody may be left over. Read the two positive group sizes. Starting with the smaller group size, work downward until you find the largest team size that divides both groups exactly.

First group: 120
Second group: 48
Largest shared team size: 24

The starter sets team_size to min(first, second), the largest possible answer. A team size divides a group exactly when first % team_size is 0. Loop while at least one of the two remainders is not 0, and subtract 1 from team_size on each pass. For 120 and 48 the search starts at 48 and stops at 24, the first value where both remainders are 0. A team size of 1 divides every positive group size, so the search always stops.

TypedOutput
120, 48Largest shared team size: 24
7, 5Largest shared team size: 1
36, 36Largest shared team size: 36
9, 27Largest shared team size: 9
1, 40Largest shared team size: 1
Rules the checker enforces
  • Repeat the work with a while loop. No for.
  • Use % to test whether team_size divides a group exactly.
  • Search for the answer with the loop. No import and no gcd.
  • Decrease team_size by 1 on each pass.
  • One print(), after the loop.

Keep the lines first = int(input('First group: ')) and second = int(input('Second group: ')) unchanged. The checker will type the other group sizes.

🐉 Boss 3: Binary to Decimal

You are given a string bits made of the characters 0 and 1. It is a number written in binary. Print the same number in decimal.

Read bits with input(), work through the characters from left to right with a while loop, and print the value once after the loop.

Example 1
Input: bits = "101101"
Output: 45
Explanation: 1*32 + 0*16 + 1*8 + 1*4 + 0*2 + 1*1 = 45.
Example 2
Input: bits = "1000"
Output: 8
Explanation: only the leftmost digit is 1, and it stands for 2*2*2 = 8.
Example 3
Input: bits = "0"
Output: 0
Constraints
  • 1 <= len(bits) <= 20
  • bits contains only the characters 0 and 1

The program reads the string after the prompt Binary: and prints Decimal: followed by the value.

Binary: 101101
Decimal: 45

The starter sets index and value to 0. Loop while index < len(bits). On each pass, bits[index] is one character and int(bits[index]) turns it into 0 or 1. Replace value with value * 2 plus that digit, then add 1 to index. For 101101 the value goes 1, 2, 5, 11, 22, 45. The one-character input 0 leaves the value at 0.

TypedOutput
101101Decimal: 45
0Decimal: 0
1Decimal: 1
1000Decimal: 8
11111111Decimal: 255
Rules the checker enforces
  • Repeat the work with a while loop. No for.
  • Test index against len(bits) so every character is processed once.
  • Pick one character out of bits with bits[index].
  • Build the value one digit at a time. int(bits, 2) is not part of this course.
  • Double the value built so far before adding the new digit.
  • One print(), after the loop.

Keep the line bits = input('Binary: ') unchanged. The checker will type the other strings.

💀 Boss 4: Circle Estimate

A short alternating calculation can estimate π. Start at 0, then add 4/1, subtract 4/3, add 4/5, subtract 4/7, and continue with odd denominators. Read a positive number of terms. After adding each term, print the term number and the current estimate with six digits after the decimal point.

Terms: 4
After 1: 4.000000
After 2: 2.666667
After 3: 3.466667
After 4: 2.895238

The starter sets step to 1, denominator to 1, sign to 1, and estimate to 0.0. Loop while step <= terms. On each pass, add sign * 4 / denominator to estimate and print the step and the estimate with :.6f. Then add 2 to denominator, replace sign with -sign, and add 1 to step. The first pass adds 4/1 and prints 4.000000; the second subtracts 4/3 and prints 2.666667. The inclusive test produces exactly the requested number of lines.

Rules the checker enforces
  • Repeat the work with a while loop. No for.
  • Build the estimate with the loop. No import and no math.
  • Show the estimate with :.6f in the f-string.
  • One print(), inside the loop.
  • Add 2 to denominator on every pass so it moves through 1, 3, 5, 7 and so on.
  • Flip sign on every pass so the terms alternate between adding and subtracting.
  • Add 1 to step on every pass and stop after terms passes.

Keep the line terms = int(input('Terms: ')) unchanged. The checker will type the other term counts.
