1. A loop repeats work

A loop repeats a block of statements. A loop is useful when the same kind of work must happen several times. Without a loop, printing the numbers 1 through 5 would require five separate statements. A while loop expresses the repeated action once.

The indented statements are the loop body. One complete execution of the body is an iteration, also called a pass.

2. Spot repetition in a problem

Problem statements often describe a loop without using the word loop. Look for words such as repeat, each, every, until, keep going, total, and count.

Consider this problem:

An investment starts at $100 and grows by 50 percent each year. Report how many years it takes to reach at least $200.

The phrase each year until the balance reaches $200 describes repetition. The exact number of years is not known before the program starts, so a condition must decide when to stop.

The six problem-solving stages organize the work:

  1. Understand: Identify the starting balance, growth rate, target, and required result.
  2. Decompose: Set up the values, repeat one year's calculation, then report the answer.
  3. Find patterns: This is a keep-going-until-a-target loop.
  4. Design: Start at year 0. While the balance is below the target, add one year and update the balance.
  5. Implement: Translate that design into Python.
  6. Reflect: Trace small values and test a case that reaches the target exactly.

3. A while loop tests a condition

A while statement has a Boolean condition, a colon, and an indented body.

while condition:
    statement
    statement

Python follows this cycle:

  1. Evaluate the condition.
  2. If it is True, run the body.
  3. Return to the condition and test it again.
  4. Stop when the condition is False.

The condition means keep going while this is true. It does not mean stop when this becomes true.

The loop continues while the balance is below the target. It stops as soon as balance < target becomes False.

4. Every while loop needs three parts

A useful while loop has three connected parts.

InitializeGive the loop variable its first valuecount = 1
TestDecide whether another iteration should runcount <= 5

Initialization happens once, before the loop. The test happens before every possible iteration. The update normally happens inside the body.

6. A while loop may run zero times

Python tests the condition before the first iteration. If the condition starts as False, the body does not run.

This is a zero-iteration loop. It is not automatically an error. Sometimes there is no work to do. Any result needed after the loop should still be initialized before the loop.

7. An infinite loop never reaches its stopping point

An infinite loop keeps running because its condition never becomes False. This example is missing its update:

count = 1
while count <= 5:
    print(count)

The program prints 1 repeatedly. The value of count never changes, so the condition stays true. Press Ctrl+C to interrupt a program that is stuck in an infinite loop.

An update can also move in the wrong direction:

count = 5
while count > 0:
    print(count)
    count = count + 1

Here count grows, so it never becomes 0. When a loop does not stop, check the test and update together. Every possible path through the body must move the program toward a false test.

9. An accumulator builds a result

An accumulator stores a result that grows during a loop. For a sum, start at 0 and add each new value.

The accumulator must be initialized before the loop. If total = 0 were inside the body, every iteration would erase the earlier work.

For a product, start at 1. Starting at 0 would make every later product 0.

10. A counter records how many times something happens

A counter is a variable that increases by 1 when an event occurs. It counts items rather than adding their values.

The variables have different jobs:

  • number controls the loop and changes every iteration.
  • evens changes only when the condition is true.

The update to number is outside the if. If it were inside, odd values would never update and the loop would become infinite.

11. A loop can read until the user stops

Sometimes the number of values is unknown. The program can read once before the loop, test the text, process it, and then read again.

Sample run:

Value, or press Enter to finish: 12.5
Value, or press Enter to finish: 7.5
Value, or press Enter to finish: 
Total: 20.00

The first input call gives the condition a value to test. The second gets ready for the next test. This duplicated read is sometimes called a loop and a half. Lecture 13 studies this input pattern and introduces sentinels and another structure for stopping.
