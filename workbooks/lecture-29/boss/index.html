How bosses work

These problems use exceptions from Lecture 29:

  • try and except blocks that name the exception types
  • several except blocks, and a tuple of exception types in one block
  • the exception object from except ... as err

They use only what Lectures 4 to 29 covered:

  • input() with int() and float(), and a blank line that ends the input
  • f-strings such as :.1f
  • if tests, while loops, lists, the list method index, and functions

Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem reads its values with a plain input() that shows no prompt, so the output is only what your program prints. Check runs your program several times and types a different sequence of answers each time. Every run must print exactly what the table shows.

Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Pick an item

Write a program that reads a position and prints an item from this list: ["pen", "book", "cup", "bag", "ruler"].

  • Positions start at 1.
  • A position of 0 or a negative position is out of range.
  • Print Out of range. for any position outside the list.
  • Print Enter a whole number. for text that is not a whole number.
Example 1
Input:
3
Output:
cup
Explanation:
Position 3 contains cup.
Example 2
Input:
0
Output:
Out of range.
Explanation:
Position 0 is outside the allowed positions.
Constraints
  • Read one line of text with a plain input() that shows no prompt.
  • Handle ValueError and IndexError separately.
  • Use an if test for positions below 1. Use no bare except.

🐉 Boss 3: Two trip speeds

Write a program that reads a distance and a time for each of two trips. Each value is on a separate line. Print the speed for each trip.

  • For the first trip, print Bad number. for invalid number text.
  • For the first trip, print Zero time. when the time is zero.
  • For the second trip, use trip_speed(distance_text, time_text).
  • For either error in the second trip, print Bad trip. and the exception message on the next line.
  • Print a successful speed as Speed: followed by the number to one decimal place.

  • Handle ValueError and ZeroDivisionError separately for the first trip.
  • Use one grouped except (ValueError, ZeroDivisionError) as err: for the second trip.
  • Keep each try block small. Use no bare except.

💀 Boss 4: Grade conversion

Write a program that reads grade values until a blank line. Convert each value between grade points and letter grades.

  • First attempt to convert each value to grade points with float.
  • For points from 0.0 to 4.0, print the nearest letter grade in the table.
  • For a tie between two point values, use the higher point value.
  • For 4.0, print A+.
  • Points outside 0.0 to 4.0 are invalid.
  • If number conversion fails, use the value as a letter grade.
  • Print the corresponding grade points for a valid letter grade.
  • Print Invalid grade. if neither conversion succeeds.

  • Test the numeric range with if. Use no bare except.
