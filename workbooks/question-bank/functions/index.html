About this bank

15 programming questions in the style of Part 2 of a term test, each worth 10 points, for term tests and the final exam. Each one asks for a complete program with functions that take parameters and return values, a main() function, and the __main__ guard. Some use default and keyword arguments. Earlier material (strings, decisions, loops, input validation) is used freely. Nothing needs lists, exceptions or files.

The questions are in order of difficulty, from 👹 to 💀: 1 at 2.5, 7 at 3, 2 at 3.5, 3 at 4, 2 at 5. Each one has the statement, two examples, the constraints, the rules the checker enforces, and, after the editor, a marking rubric and the common mistakes. Check runs the program on the examples and more inputs, and also calls each function directly, so a function that prints instead of returning does not pass. Open in PyLab shows the question beside a full-screen editor.

Programs here read values with a plain input() that shows no prompt, so the examples show only what the program prints. On a test paper, add prompts and sample runs.

This page opens only in instructor mode. It is not linked for students.

👾 Question 3: Memorial student number

10 points · Difficulty 3 of 5 · Lectures 18 to 20; also 7, 11, 13 and 14

Given student numbers typed one per line, keep reading until a valid one arrives. After each invalid number print Not a valid student number. Try again. Then print the entry year and the number of attempts.

In this question, a Memorial student number is valid when all of these are true:

  • It has exactly 9 characters, and all of them are digits.
  • It starts with 20. The first 4 digits are the year the student started.
  • The last digit is a check digit: it equals the sum of the first 8 digits, mod 10.

For example, in 202412348 the first 8 digits add up to 2+0+2+4+1+2+3+4 = 18, and 18 mod 10 is 8, the last digit. So it is valid.

Read the student numbers one per line with input(), and stop at the first valid one.

Output:

Attempts: 3
Explanation: 2024123 is too short. In 202412345 the check digit should be 8, not 5. 202412348 is valid on the third attempt.
Example 2
Input: numbers = 202301233
Output:
Entry year: 2023
Attempts: 1
Explanation: 2+0+2+3+0+1+2+3 = 13, and 13 mod 10 is 3, the last digit, so the first number is valid.
Constraints
  • A line can hold any characters, including letters, and can have spaces around it.
  • The last line is always a valid student number.

  • End the file with the __main__ guard. Only uppercase constants are assigned at the top level.
Marking rubric (10 points)
What we look forPoints

🐉 Question 11: Run-length encoding

10 points · Difficulty 4 of 5 · Lectures 18 to 20; also 7, 11, 12 and 14

Given a line of text, print it compressed with run-length encoding, then expand the compressed text back and print it, then say how much shorter or longer the compressed text is.

Run-length encoding writes each run of the same character as the character followed by the length of the run. WWWWBBBW becomes W4B3W1, and a run of 12 spaces becomes a space followed by 12. To expand, read a character, then all the digits after it as one number, and repeat the character that many times.

Read text with input() and print three lines.

Example 1
Input: text = WWWWWWWWWWWWBWW
Output:
Compressed: W12B1W2
Expanded: WWWWWWWWWWWWBWW
Shorter by 8 characters
Explanation: A run of 12 W, one B and two W. The code has 7 characters instead of 15, so it is 8 shorter. The 12 is read back as one number.
Example 2
Input: text = Hello
Output:
Compressed: H1e1l2o1
