How bosses work

These problems use the functions from Lecture 17: a def with empty parentheses, a docstring as the first statement of the body, definitions placed before the calls, and one clear job for each function. They use only what Lectures 4 to 17 covered: input() with int() and float(), arithmetic, % formatting, if, elif and else, while and for loops, and nested loops. None of the functions takes parameters or returns a value. Test each function on its own as well as the complete program. Each problem lists the rules its checker enforces. A program that prints the right answer but breaks a rule does not pass. Term tests and the final exam have questions of this kind, and you write the code in PyLab there as well.

Every problem here that reads values uses a plain input() that shows no prompt, so the output is only what your program prints. Keep the input lines exactly as the starter shows them: Check runs your program several times, typing a different sequence of answers each time, and every run must print exactly what the examples show. Defeat a boss and its marker on the workbooks page is crossed off.

Press ▶ Run to try your program and Check to fight the boss. The bosses get harder from 👹 to 💀 and are worth 10, 15, 20, and 25 XP.

👹 Boss 1: Practice notice

Given no input, produce a three-part notice. Define show_heading, show_details, and show_closing. Call them in that order. The heading prints Practice notice; the details print Topic: functions and Task: test each part; the closing prints Keep your results.

Example 1
Input:
(none)
Output:
Practice notice
Topic: functions
Task: test each part
Keep your results.
Explanation:
Each function supplies one part of the notice.
Example 2
Input:
(none; run the program again)
Output:
Practice notice
Topic: functions
Task: test each part
Keep your results.
Explanation:
The fixed notice is the same on every run.
Constraints
  • Read no input; print exactly the four specified lines.
  • Use the three named functions with empty parentheses and a docstring in each.
  • Put the definitions before the calls.

Check runs the program twice, as in the two examples, and also calls each function on its own.

Rules the checker enforces
  • Read no input; the notice is fixed.
  • Define show_heading, show_details, and show_closing with empty parentheses and a docstring as the first statement of each body.
  • Each function prints only its own part: show_heading prints Practice notice, show_details prints Topic: functions and Task: test each part, and show_closing prints Keep your results.
  • Call each function once, after all three definitions.

👾 Boss 2: Framed rows

Given a row count from 0 to 4, produce a pattern between two borders. Each border is exactly six = characters. Each row contains six * characters. Define print_border once and call it before and after a nested loop that prints the rows. A nested loop is a loop inside another loop.

Example 1
Input:
2
Output:
======
******
******
======
Explanation:
Two rows appear between the borders.
Example 2
Input:
0
Output:
======
======
Explanation:
Zero rows leave the borders on consecutive lines.
Constraints
  • Read one whole number from 0 to 4 at the top level.
  • Each border and pattern row has six characters.
  • Use a documented function with empty parentheses, called exactly twice.
  • Use nested loops for the pattern body. Do not use string repetition for its rows.

The program reads the row count with no prompt.

Rules the checker enforces
  • Define print_border with empty parentheses and a docstring as the first statement of its body.
  • print_border prints exactly six = characters and nothing else.
  • Call print_border exactly twice: once before the rows and once after them.
  • Use nested loops for the pattern rows.
  • Do not use string repetition for the rows; print each * in the inner loop.

Keep the line rows = int(input()) unchanged. The checker will type the other row counts.

🐉 Boss 3: Group entry report

Given ages for a group visiting a theatre, produce a total entry cost. For this problem, ages 0 to 4 cost nothing, ages 5 to 15 cost $8 each, ages 16 to 59 cost $15 each, and ages 60 to 120 cost $10 each. Read one age per line until a blank line. Print Group entry, the total as Total: $ followed by two decimal places, and End of report. An empty group has total $0.00.

Define show_heading, report_group_cost, and show_closing, then call them in that order. The middle function owns the whole cost report: it reads the ages, adds their prices, and prints the total. Keeping those steps together lets this function finish its task without passing values between functions.

Example 1
Input:
4
5
16
60
(blank line)
Output:
Group entry
Total: $33.00
End of report
Explanation:
The four prices are $0, $8, $15, and $10.
Example 2
Input:
(blank line)
Output:
Group entry
Total: $0.00
End of report
Explanation:
No ages means there are no charges to add.
Constraints
  • Read 0 to 20 ages, each a whole number from 0 to 120, followed by a blank line.
  • These prices are rules for this problem.
  • Use the three named, documented functions with empty parentheses.
  • Use a sentinel loop and an if/elif/else chain.
  • Keep the input, calculation, and total output inside report_group_cost.

The program reads one age per line with no prompt, inside report_group_cost.

💀 Boss 4: Two growth tables

Given an initial balance, produce two separate three-year growth tables. A balance is an amount of money. Each year, interest adds a percentage of the current balance. For the first table use 2 percent per year; for the second use 5 percent per year. Start each table from the same initial balance. Apply each year's interest by multiplying the current balance by 1.02 or 1.05. Round only the displayed amounts to two decimal places.

Read the initial balance once at the top level. Print Rate: 2% and Rate: 5% as the table headings. Under each heading print years 1, 2, and 3, with the year and balance separated by one space. Print ten hyphens before the first heading, between the tables, and after the second table. Define print_separator once and use it for all three separators. A zero balance stays zero in both tables.

Example 1
Input:
100
Output:
----------
Rate: 2%
1 102.00
2 104.04
3 106.12
----------
Rate: 5%
1 105.00
2 110.25
3 115.76
----------
Explanation:
Each table starts from 100 and applies its own rate three times.
Example 2
Input:
0
Output:
----------
Rate: 2%
1 0.00
2 0.00
3 0.00
----------
Rate: 5%
1 0.00
2 0.00
3 0.00
----------
Explanation:
Multiplying zero by either growth factor leaves zero.
Constraints
  • Read one decimal amount from 0 to 10000, with at most two decimal places.
  • Print three years for each of the two specified rates.
  • Use a documented print_separator function with empty parentheses, defined once and called three times.
  • Keep the input and growth loops at the top level.
  • Reset the balance to the initial amount before the second table.

The program reads the initial balance with no prompt.
