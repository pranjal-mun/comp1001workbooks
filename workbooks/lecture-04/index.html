1. Variables and Assignment

A program needs to keep values so it can use them later. A variable is a name that refers to a value. A statement is an instruction in a program.

An assignment statement gives a name a value. In price = 24.95, the name is on the left of = and the value is on the right. Read it as “store the value 24.95 under the name price.”

print() displays the value between its parentheses. Each call below ends its output with a new line. Assignment itself does not display anything.

price⟶24.95

The first assignment creates the name. Later statements can use that name to refer to its current value. Text values are written inside matching quotes; the quotes mark the text and are not part of it.

2. Reassignment

A later assignment to the same name replaces the value that the name refers to. Python executes these statements from top to bottom.

The first print uses the old value. The second uses the new value. Changing bottles does not change output that has already been printed.

Assignment and Addition

The sign = is an instruction to assign a value, not a claim of mathematical equality. In this example, + adds two whole numbers. An expression is code that Python evaluates to get a value.

For count = count + 1, Python:

  1. looks up the old value of count, which is 4;
  2. evaluates the right side, 4 + 1, to get 5; and
  3. makes count refer to 5.

The right side is evaluated before the assignment happens. The name must already have a value when the right side uses it.

3. Values and Types

A type identifies the kind of value Python is working with. A literal writes a value directly in the code, such as 42 or 'hello'.

TypePurposeExamples
intWhole numbers0, 42, -7
floatFloating-point numbers3.14, -0.5, 2.0
strText in matching quotes'hello', "COMP 1001"
boolBoolean valuesTrue, False

An int has no fractional part. Python integers have no fixed maximum size, although available memory limits what can be stored. A float can represent a fractional part; the decimal-point literals shown here are floats. We will study arithmetic and the limits of floating-point numbers separately.

2 is an int, while 2.0 is a float, even though both describe the number two. The text '2' is a str; quotes make it text. Single and double quotes both work when they match.

A bool has exactly two values: True and False, with capital first letters and no quotes. For now, recognize these values and their type. Comparing values comes later.

Inspecting a Type

A function is a named operation that you call with parentheses. type() returns the type of the value inside its parentheses. print(type(42)) asks for the type first, then displays it.

The word class is part of Python's display for a type. For now, focus on the type name between the quotes. You can also pass a variable name to type() to inspect its current value.

4. Dynamic Typing

Python does not require a type declaration when a variable is created. The type belongs to the value. Reassigning a name can change both its value and the type of value it refers to. This behaviour is called dynamic typing.

print() can display more than one value: separate them with commas inside the parentheses. It places a space between them. A comma here separates the items to display; it is not part of either value.

Python permits this change. A clear program normally keeps one kind of information in each variable. Changing a number to text without a reason can make later code harder to understand or cause an error.

5. Valid and Readable Names

A variable name is also called an identifier. Names may contain letters, digits, and underscores. They cannot start with a digit or contain spaces or hyphens. Names are case-sensitive: total and Total are different names.

NameValid?Reason
unit_priceYesLetters and an underscore
room2YesA digit is allowed after the first character
2nd_roomNoStarts with a digit
unit-priceNoA hyphen is not allowed
classNoA reserved keyword

Python keywords are reserved words with special meanings. They cannot be variable names. You do not need to memorize the full list now.

The course naming convention is lower_case_with_underscores. A good name describes the information it holds: unit_price is clearer than up or x2. A name can be valid Python without following the course convention.

6. Constants and Comments

Some values are intended to stay fixed while a program runs. Python programmers write their names in ALL_CAPS.

These names are constants by convention. Python does not prevent a later assignment. Capital letters tell human readers that the value should stay fixed. A descriptive constant explains an otherwise unexplained number and gives you one place to update the setting.

A comment begins with #, outside a quoted string, and continues to the end of the line. Python ignores the comment. A comment can occupy its own line or follow a statement.

The quoted label is displayed as text, followed by a space and the value. This is ordinary print() output.

Useful comments explain why a choice was made or clarify a value's meaning. Avoid comments that merely repeat an obvious line of code. For example, MAX_ATTEMPTS = 3 # Limit repeated guesses. gives a reason for the limit.
